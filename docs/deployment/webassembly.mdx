发布 Avalonia Browser 项目时，.NET SDK 会把你的应用编译成 WebAssembly（Wasm）——一种可直接在浏览器中运行的二进制格式。产物是一个静态站点，包含一个 `index.html` 文件、编译好的 `.wasm` 模块、.NET 运行时文件，以及各类静态资产。这里没有任何服务端代码，一切都在浏览器的 Wasm 运行时中于客户端执行。

既然产物全是静态文件，你就可以把它托管在任意 Web 服务器或静态托管服务上，比如 Azure Static Web Apps、GitHub Pages、AWS S3、Nginx 或任意 CDN。服务器上不需要 .NET 运行时。

## 发布 {#publishing}

在 Browser 项目目录下运行：

```bash
dotnet publish -c Release
```

SDK 会把应用包产出到 `bin/Release/<tfm>/publish/wwwroot`，其中 `<tfm>` 对应你的目标框架（比如 `net9.0-browser` 或 `net8.0-browser`）。发布产物的结构如下：

<FileTree data={[

        name: 'app.css',

        comment: 'stylesheets (if any)'
      }

这个 `wwwroot` 目录里就是部署应用所需的全部内容，把它的内容上传到你的托管服务即可。

:::note
在较老的 .NET SDK 版本中，应用包位于 `bin/Release/<tfm>/browser-wasm/AppBundle`。
:::

:::caution
给 `dotnet publish` 加上 `-o` 或 `--output` 参数，并不会把应用包放进你指定的输出目录，你还是得去 `bin` 目录里取。详见 [dotnet/runtime#94319](https://github.com/dotnet/runtime/issues/94319)。
:::

## 本地测试 {#testing-locally}

部署之前，你可以用 [dotnet-serve](https://github.com/natemcmaster/dotnet-serve) 在本地把发布产物跑起来：

```bash
dotnet tool install --global dotnet-serve

dotnet serve -d:bin/Release/net9.0-browser/publish/wwwroot
```

然后打开终端输出中显示的那个 URL（比如 `http://localhost:49875`），确认应用表现符合预期。

## 优化包体积 {#optimizing-bundle-size}

WebAssembly 应用会带上 .NET 运行时和所有被引用的程序集，因此首次下载可能相当大。可以考虑下面几招来缩小体积：

- **裁剪**：发布版构建默认启用。链接器会从你的程序集中移除未使用的代码。请确保你的代码兼容裁剪，以免运行时报错。
- **压缩**：大多数托管服务会自动用 Brotli 或 gzip 压缩后再传输。若你的服务商没有，请自行配置。Brotli 通常能把 `.wasm` 文件压掉 60%–70%。
- **AOT 编译**：在项目文件中加上 `<RunAOTCompilation>true</RunAOTCompilation>`，会把 IL 提前编译成 Wasm，运行时性能更好，代价是下载体积变大、构建时间变长。

## 定制加载画面 {#customizing-the-loading-screen}

在 .NET 运行时和应用文件下载期间，浏览器会显示一个启动画面。Avalonia 默认模板里是一句「Powered by Avalonia」加上 Avalonia 徽标，它定义在 Browser 项目 `wwwroot` 目录下的 `index.html` 文件中：

```html
<div id="out">
    <div class="avalonia-splash">
        <h2>
            Powered by
            <a href="https://www.avaloniaui.net/" target="_blank">
                <!-- Avalonia SVG logo -->
            </a>
        </h2>
    </div>
</div>
```

想换成你自己的品牌标识或加载指示，编辑 `<div id="out">` 元素里的标记即可。这段内容会一直显示到 Avalonia 初始化完毕、接管页面为止。样式可以在配套的 `app.css` 文件中调整。

## 托管注意事项 {#hosting-considerations}

由于产物是静态站点，你的 Web 服务器必须配置成以 `application/wasm` 内容类型提供 `.wasm` 文件。大多数现代服务器默认就这么做，但若应用加载失败，这是第一个该查的地方。
