Avalonia 应用可面向 Windows、macOS、Linux、iOS、Android 和 WebAssembly。支持程度因操作系统版本而异，分为三个等级。每逢 Avalonia 大版本发布都会重新审视这些等级，因此平台所处的等级可能随时间变动。

## 支持等级 {#support-tiers}

:::tip[第 1 级：完整测试并支持]
每个版本都会测试。第 1 级平台上的缺陷会被修复，社区 PR 也会得到积极审阅与合并。
:::

:::info[第 2 级：尽力而为]
不在测试矩阵之列，但会尽力保持可用。相关问题的优先级排在第 1 级工作之后，有些可能始终不会被修复。社区 PR 逐案评估；若维护负担过重，修复可能需要有[商业合作](https://avaloniaui.net/support)托底。
:::

:::caution[第 3 级：仅提供商业支持]
凡未列入第 1 级或第 2 级的平台皆属此列。相关问题会被关闭，PR 也不会被审阅。若你需要在第 3 级平台上用 Avalonia，请见[增强支持](https://avaloniaui.net/support)。
:::

## Windows

在 Windows 上，Avalonia 直接使用 Win32 API。除 .NET SDK 外，不需要额外的工作负载或依赖。

| 版本 | 最低内部版本 | 体系结构 | 等级 |
|---|---|---|---|
| Windows 11 | 24H2（内部版本 26100） | x64、ARM64 | <TierBadge tier={1} /> |
| Windows 11 | 22H2（内部版本 22621） | x64、ARM64 | <TierBadge tier={2} /> |
| Windows 10 | 22H2（内部版本 19045） | x64 | <TierBadge tier={2} /> |
| Windows 10 / 11 | 更早的内部版本 | x64、x86 | <TierBadge tier={3} /> |

关于 WinForms 互操作及其他 Windows 专属特性，请见 [Windows 平台指南](/docs/platform-specific-guides/windows)。

## macOS

Avalonia 自带原生的 Objective-C++ 后端，不使用标准的 .NET macOS 工作负载。应用可以在 Windows 或 Linux 上交叉编译。

| 版本 | 名称 | 体系结构 | 等级 |
|---|---|---|---|
| macOS 26 | Tahoe | ARM64（Apple Silicon）、x64 | <TierBadge tier={1} /> |
| macOS 15 | Sequoia | ARM64、x64 | <TierBadge tier={2} /> |
| macOS 14 | Sonoma | ARM64、x64 | <TierBadge tier={2} /> |
| macOS 13 及更早版本 | | | <TierBadge tier={3} /> |

关于原生菜单、平台惯例和嵌入原生视图，请见 [macOS 平台指南](/docs/platform-specific-guides/macos)。

## iOS 与 iPadOS {#ios-and-ipados}

.NET 在 iOS 上的支持跟着 MAUI 的生命周期走。一旦微软依据 [MAUI 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/maui)停止支持某个移动操作系统版本，我们对该版本的支持也随之终止。

| 版本 | 体系结构 | 等级 |
|---|---|---|
| iOS / iPadOS 26 | ARM64 | <TierBadge tier={1} /> |
| iOS 18.x | ARM64 | <TierBadge tier={2} /> |
| iOS 17.x 及更早版本 | ARM64 | <TierBadge tier={3} /> |

**最低 .NET 版本：**.NET 10.0。移动端的 .NET 版本遵循 [MAUI 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/maui)。微软已从 .NET 10 SDK 中移除 .NET 8 的移动工作负载，因此用 .NET 10 SDK 是构建不出 .NET 8 iOS 版本的。

配置步骤请见 [iOS 平台指南](/docs/platform-specific-guides/ios)。

## Android

.NET 在 Android 上的支持跟着 MAUI 的生命周期走。一旦微软依据 [MAUI 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/maui)停止支持某个移动操作系统版本，我们对该版本的支持也随之终止。

| 版本 | API 级别 | 体系结构 | 等级 |
|---|---|---|---|
| Android 16 | API 36 | ARM64、x64 | <TierBadge tier={1} /> |
| Android 12 至 15 | API 31 至 35 | ARM64、ARM32、x64 | <TierBadge tier={2} /> |
| Android 11 及更早版本 | API 30 及以下 | | <TierBadge tier={3} /> |

**最低 .NET 版本：**.NET 10.0。移动端的 .NET 版本遵循 [MAUI 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/maui)。微软已从 .NET 10 SDK 中移除 .NET 8 的移动工作负载，因此用 .NET 10 SDK 是构建不出 .NET 8 Android 版本的。

配置步骤请见 [Android 平台指南](/docs/platform-specific-guides/android)。

## Desktop Linux

在 Linux 上，Avalonia 直接面向 X11。从 Avalonia 12.1.0 起另有一个实验性的原生 Wayland 后端包可供选用，配置步骤请见 [Linux 平台指南](/docs/platform-specific-guides/linux#wayland)。只要能装 .NET SDK 且具备 X11 或 framebuffer 能力的发行版，大多都能跑 Avalonia 应用。

| 发行版 | 版本 | 体系结构 | 等级 |
|---|---|---|---|
| Ubuntu | 25.x | x64、ARM64 | <TierBadge tier={1} /> |
| Fedora | 43 | x64 | <TierBadge tier={1} /> |
| Debian | 13 (Trixie) | x64、ARM64 | <TierBadge tier={1} /> |
| Ubuntu | 16.04 至 24.x | x64、ARM64 | <TierBadge tier={2} /> |
| Fedora | 30 to 42 | x64 | <TierBadge tier={2} /> |
| Debian | 9（Stretch）至 12 | x64、ARM64 | <TierBadge tier={2} /> |
| 其他发行版 | （Arch、Alpine、NixOS、Gentoo 等） | Varies | <TierBadge tier={3} /> |

**渲染：**经 Skia 走 OpenGL（X11）、经 EGL 走 OpenGL 或 OpenGL ES（Wayland）、软件渲染（framebuffer）。
**glibc 要求：**Skia 是针对 glibc 2.17 构建的。使用其他 C 库（比如 musl）的发行版需要自行构建 `libSkiaSharp.so`，细节见 [SkiaSharp](https://github.com/mono/SkiaSharp)。需要自行构建 Skia 的发行版属于第 3 级。

**必需的软件包：**
```bash
libx11-6 libice6 libsm6 libfontconfig1
```

关于 WSL 2 及其他配置细节，请见 [Linux 平台指南](/docs/platform-specific-guides/linux)。

### Embedded Linux

Avalonia 支持借助 Linux framebuffer 或 DRM（Direct Rendering Manager），在没有桌面环境的嵌入式 Linux 设备上运行。

| 发行版 | 体系结构 | 运行时标识符 | 等级 |
|---|---|---|---|
| Raspberry Pi OS | ARM64, ARM32 | `linux-arm64`, `linux-arm` | <TierBadge tier={1} /> |
| 其他嵌入式 Linux | Varies | Varies | <TierBadge tier={3} /> |

**必需的软件包：**`libgbm1`、`libgl1-mesa-dri`、`libegl1-mesa`、`libinput10`

关于显示输出配置和设备准备，请见[嵌入式 Linux 指南](/docs/platform-specific-guides/embedded-linux)。

## WebAssembly

Avalonia 可以跑在任何完整支持 WebAssembly 的浏览器里，不需要任何服务端组件。

| 要求 | 详情 |
|---|---|
| .NET 版本 | .NET 8 或更高 |
| 浏览器支持 | 所有支持 WebAssembly 的浏览器（[Can I use WebAssembly](https://caniuse.com/wasm)） |
| Rendering | 经 CanvasKit 走 Skia（WebGL） |

关于配置与部署，请见 [WebAssembly 平台指南](/docs/platform-specific-guides/webassembly)。

| WebAssembly | .NET 8.0 | |

## 贡献平台专属修复 {#contributing-platform-specific-fixes}

我们欢迎针对特定平台的贡献，但为了项目的长期健康，这些贡献需要与上述等级划分相匹配。

**第 1 级**的修复随时欢迎，走常规审阅流程即可。

**第 2 级**的修复逐案评估。审阅时会权衡改动的复杂度、拖累第 1 级的回归风险，以及后续的维护成本。若维护负担过重，这项工作可能需要有商业合作托底。

**第 3 级**的修复需先有商业合作才会进入审阅。无论改动看上去多小都是如此——因为成本不在补丁本身，而在于一版接一版地维护和测试它。

若拿不准你的贡献是否需要商业合作，不妨动手之前先问一声，省得白费功夫。
