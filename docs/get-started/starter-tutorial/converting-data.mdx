要让温度换算器真正完工，还得让它能接收一个数值输入，并按指定公式换算成另一个数值。

## 给控件命名 {#naming-your-controls}

想在应用中区分不同控件，可以给它们起名字。下面就给那两个 `TextBox` 控件各起一个。

1. 如果应用还在运行，先把它停掉。
2. 在 **MainWindow.axaml** 文件中找到摄氏度文本框：`<TextBox Grid.Row="0" Grid.Column="1" Margin="0 5" Text="0"/>`
3. 像下面这样给 `<TextBox>` 标签加上 `Name` 特性：

```xml
<TextBox Grid.Row="0" Grid.Column="1" Margin="0 5" Text="0" Name="Celsius"/>
```

4. 找到华氏度文本框：`<TextBox Grid.Row="1" Grid.Column="1" Margin="0 5" Text="0"/>`
5. 像下面这样给 `<TextBox>` 标签加上 `Name` 特性：

```xml
<TextBox Grid.Row="1" Grid.Column="1" Margin="0 5" Text="0" Name="Fahrenheit"/>
```

## 读取输入值 {#getting-input-values}

接下来要让应用能够读到 `Celsius` 文本框里输入的内容。

1. 在代码隐藏文件 **MainWindow.axaml.cs** 中，找到你[之前创建的](/docs/get-started/starter-tutorial/establishing-events-and-responses) `Button_OnClick` 事件处理程序。
2. 像下面这样修改 `Debug` 语句，让它输出 `Celsius` 文本框中录入的文字：

```csharp
Debug.WriteLine($"Click! Celsius={Celsius.Text}");
```

3. 再次运行应用（如果你的 IDE 需要，请用[调试模式](/docs/get-started/starter-tutorial/establishing-events-and-responses)）。
4. 连点几次 **Calculate** 按钮。
5. 改一下 `Celsius` 文本框里的数字，再点几次 **Calculate**。
6. 查看调试输出，确认 `Celsius` 文本框的输入值确实被打印了出来。

## 实现换算公式 {#implementing-the-conversion-formula}

最后一步，是让应用套用把摄氏度换算成华氏度的数学公式，并把算出的结果显示在华氏度文本框里。

如果你对摄氏－华氏换算公式不太熟悉，它是这样的：

> 华氏度 = 摄氏度 * (9/5) + 32

下面看看怎么用 C# 代码隐藏文件实现这段逻辑。

1. 在代码隐藏文件 **MainWindow.axaml.cs** 中，找到你[之前创建的](/docs/get-started/starter-tutorial/establishing-events-and-responses) `Button_OnClick` 事件处理程序。
2. 删掉那条 `Debug` 语句。
3. （可选）文件顶部的 `using System.Diagnostics;` 语句也可以一并删掉，它已经用不上了。
4. 在 `Button_OnClick` 事件处理程序中添加这段代码，用于校验摄氏度输入是不是数字：

```csharp
if (double.TryParse(Celsius.Text, out double C))
```

5. 在 `if` 条件分支中添加这段代码，套用换算公式：

```csharp
{
    var F = C * (9d / 5d) + 32;
```

6. 再添加这段代码，把结果以文本形式输出到华氏度文本框，然后闭合条件分支：

```csharp
    Fahrenheit.Text = F.ToString("0.0");
}
```

7. 补上一个 `else` 分支，在输入非法时把两个文本框都重置为 0：

```csharp
else
{
    Celsius.Text = "0";
    Fahrenheit.Text = "0";
}
```

8. 写完之后，你的事件处理程序应该是这样：

```csharp
private void Button_OnClick(object? sender, RoutedEventArgs e)
{
    if (double.TryParse(Celsius.Text, out double C))
    {
        var F = C * (9d / 5d) + 32;
        Fahrenheit.Text = F.ToString("0.0");
    }
    else
    {
        Celsius.Text = "0";
        Fahrenheit.Text = "0";
    }
}
```

## 检查成果 {#checking-your-work}

1. 运行 **GetStartedApp**。
2. 在摄氏度输入框中依次输入下列数字，每次都点一下 **Calculate**，确认应用返回的华氏度数值正确：

| **摄氏度** | **华氏度** |
| --- | --- |
| -10 | 14.0 |
| 0 | 32.0 |
| 10 | 50.0 |
| 21 | 69.8 |
| 32.0 | 89.6 |

3. 在不改动摄氏度输入框的前提下，往华氏度输入框里随便输点东西。确认应用会把华氏度框里的内容改回由当前摄氏度算出的结果。
4. 在摄氏度输入框中输入 “abc”，确认应用会把两个文本框都重置为 0。

:::note
你可能觉得有点奇怪：应用允许在华氏度框里输入数字，却不会把它换算成摄氏度。别急，紧接着的练习环节就会把那个框改成只读。
:::
