到目前为止，你的温度换算器窗口正中只有一个按钮，而且再也塞不下别的元素了 —— 因为每个 Avalonia 窗口的内容区只允许放一个控件。（关于布局区域，下一篇[定制 Avalonia 窗口](/docs/get-started/starter-tutorial/customizing-the-avalonia-window)会详细介绍。）

想在窗口里放多个 UI 元素，就必须借助**布局控件**。

Avalonia 布局控件的完整清单，请见[控件参考](/controls)的 Layout 选项卡。

## 插入堆叠面板 {#inserting-a-stack-panel}

可以用 [`StackPanel`](/controls/layout/panels/stackpanel) 布局控件，在按钮上方放一段文字。

1. 在 **MainWindow.axaml** 文件中，用一对 `<StackPanel>...</StackPanel>` 标签把 `Button` 包起来。

```xml
<StackPanel>
	<Button>Calculate</Button>
</StackPanel>
```

2. 在 Button 上方添加一个 [`TextBlock`](/api/avalonia/controls/textblock)。（你应该还记得默认 **MainWindow.axaml** 里那个用来在窗口中显示文字的 `TextBlock` 控件。）把 `TextBlock` 的各项特性设置如下：

- `Margin="5"`
- `FontSize="24"`
- `HorizontalAlignment="Center"`
- `Text="Temperature Converter"`

```xml
<StackPanel>
    <TextBlock Margin="5"
               FontSize="24" 
               HorizontalAlignment="Center"
               Text="Temperature Converter">
    </TextBlock>

    <Button HorizontalAlignment="Center">Calculate</Button>
</StackPanel>
```

3. 运行应用，或者看一眼预览器。“Temperature Converter” 这段文字应该出现在 **Calculate** 按钮上方。

<Image light={TemperatureConverterTextOnly} alt="A screenshot showing a work-in-progress app, with text above a button." position="center" maxWidth={400} cornerRadius="true" margin="0,0,30,0"/>

4. 用一对 `<Border>...</Border>` 标签把 `TextBlock` 包起来，并把 `Border` 的各项特性设置如下：

- `Margin="5"`
- `CornerRadius="10"`
- `Background="LightBlue"`

```xml
<StackPanel>
    <Border Margin="5" CornerRadius="10" Background="LightBlue">
        <TextBlock Margin="5"
                   FontSize="24" 
                   HorizontalAlignment="Center"
                   Text="Temperature Converter">
        </TextBlock>
    </Border>

    <Button HorizontalAlignment="Center">Calculate</Button>
</StackPanel>
```

5. 运行应用，或者看一眼预览器。“Temperature Converter” 这段文字现在应该被包在一个蓝色圆角方框里。

<Image light={TemperatureConverterBlueBorder} alt="A screenshot showing a work-in-progress app, with text enclosed inside a blue border above a button." position="center" maxWidth={400} cornerRadius="true" margin="0,0,30,0"/>

:::note
[`StackPanel`](/controls/layout/panels/stackpanel) 默认把子元素纵向堆叠。把 `Orientation` 特性设为 `Horizontal` 即可改为横向排列。
:::

## 插入网格 {#inserting-a-grid}

接下来给温度换算器加一个 [`Grid`](/api/avalonia/controls/grid) 布局控件。`Grid` 会划分出由行和列构成的单元格，你可以往里面继续放控件。

1. 如果应用还在运行，先把它停掉。
2. 在 **MainWindow.axaml** 文件中，于 `</Border>` 和 `<Button>` 之间插入一个 `<Grid>...</Grid>` 标签。

```xml
<StackPanel>
    <Border Margin="5" CornerRadius="10" Background="LightBlue">
        <TextBlock Margin="5"
            HorizontalAlignment="Center"
            FontSize="24"
            Text="Temperature Converter">
        </TextBlock>
    </Border>
    <Grid ShowGridLines="True" Margin="5" 
          ColumnDefinitions="120, 100"
          RowDefinitions="Auto, Auto">
    </Grid>
    <Button HorizontalAlignment="Center">Calculate</Button>
</StackPanel>
```

我们给这个 `Grid` 指定了几项特性：

- 它有两列两行。
- 网格线可见。
- 单元格高度随内容自动伸缩。由于空单元格的自动高度为零，此刻预览器里的 `Grid` 看上去只是一条水平直线。

<Image light={TemperatureConverterEmptyGrid} alt="A screenshot showing a work-in-progress app, with a title, a dotted line, and a button." position="center" maxWidth={400} cornerRadius="true"/>

:::tip
本例中 `Grid` 放在 `StackPanel` 内部，于是整个网格的内容都会落在 “Temperature Converter” 文本框和 **Calculate** 按钮之间。布局控件可以有很多种组合方式，总能拼出你想要的界面。关于各类布局控件各自适合什么场景，请参阅[如何选择布局面板](/docs/layout/choosing-a-layout-panel)。
:::

## 往网格里放控件 {#inserting-controls-in-the-grid}

1. 在网格左侧的单元格中各放一个 `TextBlock` 控件，用 `Grid.Row` 和 `Grid.Column` 特性指定目标单元格，并让这两个文本块分别显示 “Celsius” 和 “Fahrenheit”。

:::note
`Grid` 中每行每列的第一个单元格，编号都是 0。
:::

```xml
        <Grid ShowGridLines="True" Margin="5" 
              ColumnDefinitions="120, 100"
              RowDefinitions="Auto, Auto">
            <TextBlock Grid.Row="0" Grid.Column="0" Margin="10">Celsius</TextBlock>
            <TextBlock Grid.Row="1" Grid.Column="0" Margin="10">Fahrenheit</TextBlock>
        </Grid>
```

2. 在网格右侧的单元格中各放一个 `TextBox` 控件，同样用 `Grid.Row` 和 `Grid.Column` 特性指定目标单元格。`TextBox` 这个控件会生成一块可供键盘输入的区域。

```xml
        <Grid ShowGridLines="True" Margin="5" 
              ColumnDefinitions="120, 100"
              RowDefinitions="Auto, Auto">
            <TextBlock Grid.Row="0" Grid.Column="0" Margin="10">Celsius</TextBlock>
            <TextBox Grid.Row="0" Grid.Column="1" Margin="0 5" Text="0"/>
            <TextBlock Grid.Row="1" Grid.Column="0" Margin="10">Fahrenheit</TextBlock>
            <TextBox Grid.Row="1" Grid.Column="1" Margin="0 5" Text="0"/>
        </Grid>
```

3. 运行应用，或者看一眼预览器。文字和输入框应该都已经出现在窗口中，分别落在网格线划出的单元格里。
