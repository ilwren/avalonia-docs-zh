正如[前文所说](/docs/get-started/starter-tutorial)，Avalonia 窗口就是你的应用在目标平台上的运行载体。在 .axaml 文件中，`<Window>...</Window>` 标签定义了窗口里装什么。

## 布局区域 {#layout-zones}

Avalonia 窗口有四个布局区域：（1）Margin（外边距）、（2）Border（边框）、（3）Padding（内边距）和（4）Content（内容）。

某些布局控件（比如你刚用过的 `StackPanel`）会创建出更小的子窗格，它们同样具备这四个布局区域。

:::note
每个 Avalonia 窗口的内容区只接受一个控件。
:::

## 窗口的默认特性 {#default-window-attributes}

和控件一样，Avalonia 的窗口也有一组用于定义外观和行为的 XML 特性。

滚动到 **MainWindow.axaml** 文件顶部，看看 `<Window>` 开始标签，里面已经写好了一些默认设置。

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:vm="using:GetStartedApp.ViewModels"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
        mc:Ignorable="d" d:DesignWidth="800" d:DesignHeight="450"
        x:Class="GetStartedApp.Views.MainWindow"
        x:DataType="vm:MainViewModel"
        Icon="/Assets/avalonia-logo.ico"
        Title="GetStartedApp">
```

:::note
`<Window>` 标签开头几行声明的是 Avalonia 用到的 XML 命名空间，其别名分别为 `x`、`vm`、`d` 和 `mc`。
:::

## 设置窗口的特性 {#setting-the-windows-attributes}

我们来试着把窗口尺寸调成竖屏比例（而不是默认的横屏）。开发应用时，想看看界面在移动设备上是什么样，往往就会这么做。

### 设置预览器尺寸 {#setting-the-previewer-size}

调整 `d:DesignWidth` 和 `d:DesignHeight` 的值，可以改变应用在实时预览器中的显示尺寸，而不会影响窗口在运行时的实际大小。

1. 在 **MainWindow.axaml** 文件中，于 `<Window>...</Window>` 标签内找到这一行：

```xml
mc:Ignorable="d" d:DesignWidth="800" d:DesignHeight="450"
```

2. 把 `d:DesignWidth` 设为 400。
3. 看一眼预览器，现在的预览效果应该已经接近手机屏幕了。

更多说明请参阅[预览界面设计](/docs/app-development/xaml-preview-and-design-settings)。

### 设置运行时窗口尺寸 {#setting-the-runtime-window-size}

想调整应用运行时的窗口尺寸，需要在 `<Window>` 开始标签上添加 `Width` 和 `Height` 特性。

1. 在 **MainWindow.axaml** 文件中，定位到 `<Window>` 开始标签的最后一行： 

```xml
Title="GetStartedApp">
```

2. 在这一行下面补上 `Width="400"` 和 `Height="450"` 特性，记得把尖括号移到最后。

```xml
Title="GetStartedApp"
Width="400"
Height="450">
```

3. 运行应用，窗口现在应该已经是手机屏幕的比例了。

:::note
实际上大多数移动平台会忽略窗口尺寸，自动把窗口拉伸到铺满屏幕。开发时并不需要真的为每个目标平台分别设定尺寸。
:::
