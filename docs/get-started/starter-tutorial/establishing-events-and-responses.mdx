现在温度换算器看起来已经像模像样，可惜还什么都不会做。下一步要做的，是让 **Calculate** 按钮能够响应用户操作，比如点击。

## 用代码隐藏文件创建事件处理程序 {#creating-an-event-handler-with-code-behind}

XAML 文件可以关联一个 C# 源文件，按钮的事件处理代码就写在这里。这种写法叫做 “代码隐藏”（code-behind）。

1. 在 IDE 中浏览项目目录，找到 **Views → MainWindow.axaml → MainWindow.axaml.cs**。这就是主窗口 XAML 背后的 C# 源文件。

<Image light={MainWindowCodeBehindLocation} alt="A screenshot showing the location of the main window's code-behind file in a file tree." position="center" maxWidth={400} cornerRadius="true"/>

2. Open **MainWindow.axaml.cs**.
3. 找到文件顶部的 `using` 指令。此刻应该只有 `using Avalonia.Controls;` 这一行。再补上这两条 `using` 指令：

```csharp
using Avalonia.Interactivity;
using System.Diagnostics;
```

4. 在文件稍靠下的位置找到 `public partial class MainWindow : Window` 这一行。这个类目前只包含主窗口的构造函数 `public MainWindow()`。在构造函数下方添加如下代码：

```csharp
private void Button_OnClick(object? sender, RoutedEventArgs e)
{
    Debug.WriteLine("Click!");
}
```

5. 现在你的 C# 文件应该是这样：

```csharp
using Avalonia.Controls;
using Avalonia.Interactivity;
using System.Diagnostics;

namespace GetStartedApp.Views;

public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
    }
    
    private void Button_OnClick(object? sender, RoutedEventArgs e)
    {
        Debug.WriteLine("Click!");
    }
}
```

6. 切回 XAML 文件 **MainWindow.axaml**。
7. 在文件接近末尾处找到 `<Button>`。
8. 像下面这样，给 `<Button>` 标签加上 `Click` 特性，并把它关联到 `Button_OnClick`：

```xml
<Button HorizontalAlignment="Center" Click="Button_OnClick">Calculate</Button>
```

## 验证事件处理程序是否生效 {#checking-the-event-handler-works}

要确认事件处理程序接对了，可以看调试输出：点击 **Calculate** 按钮时，应当打印出 “Click!”。

<Tabs groupId="ide">
  <TabItem value="vs" label="Visual Studio" default>
    1. 打开 **输出** 窗口（默认位于分屏视图下方）。在 “显示输出来源:” 下拉菜单中选择 **调试**。
    2. 运行应用。
    3. 在应用窗口中连点几次 **Calculate** 按钮。
    4. 输出窗口里应该会打印出 “Click!”。

    <Image light={VsDebugOutputClick} alt="A screenshot showing the output screen in Visual Studio, with the word 'Click!' printed inside." position="center" maxWidth={400} cornerRadius="true"/>

  </TabItem>
  <TabItem value="rider" label="Rider">
	1. 以调试模式运行 GetStartedApp。

    <Image light={RiderRunDebugMode} alt="A screenshot showing the location of the button to run a project in debug mode in Rider." position="center" maxWidth={400} cornerRadius="true"/>

	2. 打开底部面板中的 **Debug Output** 选项卡。
    3. 在应用窗口中连点几次 **Calculate** 按钮。
    4. 你应该能在 Rider 的调试输出中看到不断打印的 “Click!”。
  </TabItem>
</Tabs>
