温度换算器已经做好了，下面用三道练习检验一下你对 Avalonia 的理解。

## 练习 1：修改已有特性 {#exercise-1-change-an-existing-attribute}

**难度：★**

让 **GetStartedApp** 中的网格线隐藏起来。

<details>
	<summary>Hint</summary>

	你在 MainWindow.axaml 里指定过 `<Grid>`。
</details>

<details>
	<summary>Solution</summary>
	
	在 **MainWindow.axaml** 中找到 `<Grid>` 开始标签，把 `ShowGridLines` 特性改为 `False`。

	```xml
	<Grid ShowGridLines="False" Margin="5" 
      ColumnDefinitions="120, 100"
      RowDefinitions="Auto, Auto, Auto">
    ```
</details>

## 练习 2：添加新特性 {#exercise-2-add-a-new-attribute}

**难度：★★**

让用户无法在 **GetStartedApp** 的华氏度文本框中输入文字。

<details>
	<summary>提示（第 1 条）</summary>

	关于 `TextBox` 控件的更多说明，请查阅 [`TextBox` API 参考](/api/avalonia/controls/textbox)。
</details>

<details>
	<summary>提示（第 2 条）</summary>

	在 [`TextBox` 的 API 参考](/api/avalonia/controls/textbox)中，你会找到 `IsReadOnly` 这个特性。
</details>

<details>
	<summary>Solution</summary>

	在 **MainWindow.axaml** 中找到华氏度输入框对应的 `<TextBox>` 标签，加上 `IsReadOnly` 特性并设为 `True`。

	```xml
	<TextBox Grid.Row="1" Grid.Column="1" Margin="0 5" Text="0" Name="Fahrenheit" IsReadOnly="True"/>
	```
</details>

## 练习 3：编写新的事件响应 {#exercise-3-program-a-new-event-response}

**难度：★★★**

让 **GetStartedApp** 在用户输入的同时就完成温度换算。

<details>
	<summary>提示（第 1 条）</summary>

	关于 `TextBox` 控件的更多说明，请查阅 [`TextBox` API 参考](/api/avalonia/controls/textbox)。
</details>

<details>
	<summary>提示（第 2 条）</summary>

	在 [`TextBox` 的 API 参考](/api/avalonia/controls/textbox)中，你会找到 `TextChanged` 这个事件。
</details>

<details>
	<summary>提示（第 3 条）</summary>

	事件处理程序定义在 C# 代码隐藏文件 MainWindow.axaml.cs 中，同时也被 XAML 文件 MainWindow.axaml 引用。
</details>

<details>
	<summary>Solution</summary>

	1. 在 **MainWindow.axaml** 中找到摄氏度输入框对应的 `<TextBox>` 标签，加上 `TextChanged` 事件，并给它起个名字，例如 `Celsius_TextChanged`。

	```xml
	<TextBox Grid.Row="0" Grid.Column="1" Margin="0 5" Text="0" TextChanged="Celsius_TextChanged" Name="Celsius"/>
	```

	2. 在 **MainWindow.axaml** 中，把以 `<Button>` 开头的那一整行删掉，它已经用不上了。

    ~~`<Button HorizontalAlignment="Center" Click="Button_OnClick">Calculate</Button>`~~

    3. 在 **MainWindow.axaml.cs** 中找到以 `private void` 开头的事件处理程序那一行，把事件名从 `Button_OnClick` 改成你在 XAML 文件里起的名字，例如 `Celsius_TextChanged`。

    ```csharp
    private void Celsius_TextChanged(object? sender, RoutedEventArgs e)
    ```

    4. 运行应用，确认在摄氏度输入框中打字时，华氏度框里的数值会同步变化。
</details>

<details>
    <summary>进阶（可选）</summary>

    若想让摄氏度输入框也能接受空值或单独一个负号，可以这样调整代码隐藏文件：

    1. 在 **MainWindow.axaml.cs** 中找到事件处理程序 `private void Celsius_TextChanged`，新增一个 `if` 条件，允许输入为空或仅有一个负号。

    ```csharp
    if (string.IsNullOrEmpty(Celsius.Text) || Celsius.Text == "-")
        {
            Fahrenheit.Text = "";
        }
    ```

    2. 把原来那段 `double` 解析逻辑改成以 `else if` 开头，因为它现在变成了第二个条件分支。

    ```csharp
    else if (double.TryParse(Celsius.Text, out double C))
    ```

    3. 现在你的事件处理程序应该是这样：

    ```csharp
    private void Celsius_TextChanged(object? sender, RoutedEventArgs e)
    {
        if (string.IsNullOrEmpty(Celsius.Text) || Celsius.Text == "-")
        {
            Fahrenheit.Text = "";
        }
        else if (double.TryParse(Celsius.Text, out double C))
        {
            var F = C * (9d / 5d) + 32;
            Fahrenheit.Text = F.ToString("0.0");
        }
        else
        {
            Celsius.Text = "0";
            Fahrenheit.Text = "0";
        }
    }
    ```

    4. 运行应用，确认现在可以清空摄氏度输入框、或者只输入一个负号，而输入框不会被重置为 0。这种情况下华氏度框会留空。有了这点改进，你就能顺畅地输入负数了。
</details>
