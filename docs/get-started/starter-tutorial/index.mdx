## .axaml

注意到项目目录里那些以 `.axaml` 结尾的文件了吗？它是 Avalonia XAML 的缩写，这个扩展名为 Avalonia 独有，用于与标准 XAML 文件作区分。

## 确认 XAML 实时预览器可用 {#check-your-live-xaml-previewer-works}

如果你刚在 Visual Studio 或 JetBrains Rider 中装好 Avalonia，而且对 IDE 开发还不太熟悉，不妨趁现在确认一下实时 XAML 预览器能不能正常工作。

启用预览器的方法请参阅 [XAML 实时预览](/docs/app-development/xaml-preview-and-design-settings)。

## 打开主窗口文件 {#open-the-main-window-file}

在项目目录的 **Views** 文件夹中打开 **MainWindow.axaml** 文件。整个教程基本都围绕这个文件展开。

<Image light={MainWindowFileLocation} alt="A screenshot showing the location of the main window file in a file tree." position="center" maxWidth={400} cornerRadius="true" margin="20,0,50,0"/>

**MainWindow.axaml** 里几乎所有内容都写在 `<Window>...</Window>` 这个 XAML 标签之内。该标签代表 Avalonia 窗口，也就是你的应用在目标平台上的运行载体。后面讲到[定制 Avalonia 窗口](/docs/get-started/starter-tutorial/customizing-the-avalonia-window)时，我们会更深入地研究它。
