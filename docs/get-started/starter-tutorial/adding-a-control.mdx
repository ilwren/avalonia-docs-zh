做温度换算器的第一步，是往界面上添加一个**控件**。在 Avalonia 中，用户能看到或能交互的 UI 元素都叫控件：按钮、滑块、复选框、文本框、菜单等等都是。每个控件在 AXAML 标记中对应一个 XML 元素，因此增删或重排界面元素都很直接。

内置控件的完整清单请见[控件](/controls)。

## 插入一个按钮 {#insert-a-button}

先把应用里默认的那段文字换成一个 [`Button`](/api/avalonia/controls/button) 控件。

1. 如果应用还在运行，先把它停掉。
2. 在 **MainWindow.axaml** 文件中找到这一行：

```xml
<TextBlock Text="{Binding Greeting}" HorizontalAlignment="Center" VerticalAlignment="Center"/>
```

3. 把整行替换为下面的 `Button` 元素：

```xml
<Button>Calculate</Button>
```

`<Button>` 开始标签和结束标签之间的文字，就是按钮上显示的文本。这里按钮会显示 “Calculate”。

4. 运行应用，或者看一眼预览器。窗口里现在应该出现了一个 **Calculate** 按钮。
5. 试着把鼠标移到按钮上，或者点一下，看看它的外观变化。Avalonia 的默认主题已经内置了悬停、按下和获得焦点时的视觉状态，不用额外写代码，按钮就会对用户操作作出反馈。

## 设置按钮的特性 {#set-the-buttons-attributes}

Avalonia 中的控件通过 XML 特性来配置外观和行为。你可以把特性理解成直接写在 AXAML 标记里的一组设置项，用来控制尺寸、位置、颜色等等。

现在这个 **Calculate** 按钮贴在窗口左边，因为 [`HorizontalAlignment`](/api/avalonia/layout/horizontalalignment) 特性的默认值是 `Left`。想让按钮居中，就得显式设置这个特性。

1. 在 **MainWindow.axaml** 中找到刚才添加按钮的那一行：

```xml
<Button>Calculate</Button>
```

2. 给 `<Button>` 标签加上 `HorizontalAlignment` 特性，并把它设为 `Center`：

```xml
<Button HorizontalAlignment="Center">Calculate</Button>
```

3. 运行应用，或者看一眼预览器。**Calculate** 按钮应该移动到了窗口中央。

<Image light={CalculateButtonCenter} alt="A screenshot of an app running in a window, with the button aligned center." maxWidth={400} cornerRadius="true" margin="0,0,30,0"/>

:::tip
同理，[`VerticalAlignment`](/api/avalonia/layout/verticalalignment) 用于控制控件在竖直方向上的位置。可以在按钮上试试设置 `VerticalAlignment="Center"`，看看效果。
:::

## 本节小结 {#what-you-have-learned}

在本节中，你完成了：

- 通过编写 AXAML 标记，往窗口里添加了一个 `Button` 控件。
- 在开始标签和结束标签之间设置了按钮的内容（也就是它的文字）。
- 用 `HorizontalAlignment` 特性调整了按钮的位置。
