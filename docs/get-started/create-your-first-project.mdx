本文带你从模板创建一个全新的 Avalonia 应用并把它跑起来。读完之后，你的屏幕上就会出现一个真正能用的 Avalonia 窗口。

## 创建项目 {#create-the-project}

第一个项目建议使用 Model-View-ViewModel（MVVM）模板。该模板会按 MVVM 模式搭好项目骨架，这也是组织 Avalonia 应用推荐的方式。

<Tabs groupId="ide">
  <TabItem value="vs" label="Visual Studio" default>
1. 在 Visual Studio 中依次点击 **文件 → 新建 → 项目/解决方案**。
2. 在搜索框中输入 “Avalonia”。
3. 从搜索结果中选择 **Avalonia .NET MVVM App**。如果 Visual Studio 列出了多个选项，请选 **C#** 那一个，然后点击 **下一步**。
4. 把项目命名为 “GetStartedApp”。
5. 如有需要可以改一下目标目录，然后点击 **下一步**。
6. 选择你想使用的 **.NET** 版本作为目标框架。
7. 如果出现选择目标平台的步骤，请勾选 **Desktop**。
8. Click **Create**.
  </TabItem>
  <TabItem value="vsc" label="Visual Studio Code">
1. 在 Visual Studio Code 中打开命令面板：Windows 上是 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>，macOS 上是 <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>。
2. 在搜索框中输入 “.NET”。
3. 从搜索结果中选择 **.NET: New Project...**
4. 在项目模板列表中选择 **Avalonia MVVM App**。
5. 指定一个本机目录用于存放该项目。
6. 把项目命名为 “GetStartedApp”。
7. 点击 **Create project**。
  </TabItem>
  <TabItem value="rider" label="Rider">
1. 在 Rider 的启动界面中选择 **New Solution**。
2. 在侧边栏中向下滚动到 “Custom Templates”，选择 **Avalonia .NET MVVM App**。
3. 把解决方案命名为 “GetStartedApp”。
4. Click **Create**.
  </TabItem>
  <TabItem value="cli" label="Command line">
执行以下命令：

```bash
dotnet new avalonia.mvvm -o GetStartedApp
```

到本机目录下看一眼，应该多出一个名为 **GetStartedApp** 的文件夹，里面就是新建的项目文件。
  </TabItem>
</Tabs>

## 运行项目 {#run-the-project}

<Tabs groupId="ide">
  <TabItem value="vs" label="Visual Studio" default>
在顶部工具栏中，于 **运行** 按钮旁边选择 “GetStartedApp”，然后点击 **运行**。

解决方案会完成构建，并在一个新窗口中运行你的应用。默认情况下，窗口里显示的是 “Welcome to Avalonia!”。
  </TabItem>
  <TabItem value="vsc" label="Visual Studio Code">
1. 在侧边导航栏中选择 **Run and Debug**。
2. 如果提示选择调试器，请选 **C#**。
3. 点击 **Run and Debug**。

解决方案会完成构建，并在一个新窗口中运行你的应用。默认情况下，窗口里显示的是 “Welcome to Avalonia!”。
  </TabItem>
  <TabItem value="rider" label="Rider">
点击顶部工具栏中的 **Run**。

解决方案会完成构建，并在一个新窗口中运行你的应用。默认情况下，窗口里显示的是 “Welcome to Avalonia!”。
  </TabItem>
  <TabItem value="cli" label="Command line">
进入 **GetStartedApp** 项目所在目录，执行：

```bash
dotnet run
```

解决方案会完成构建，并在一个新窗口中运行你的应用。默认情况下，窗口里显示的是 “Welcome to Avalonia!”。
  </TabItem>
</Tabs>

## 项目里都有些什么？ {#whats-in-the-project}

MVVM 模板生成的项目结构如下：

| File/Folder | 用途 |
|---|---|
| **App.axaml** | 应用级别的资源和样式。`.axaml` 这个扩展名是 Avalonia XAML 的缩写。 |
| **ViewModels/** | 存放 `MainViewModel`，其中承载主窗口的数据与逻辑。 |
| **Views/MainWindow.axaml** | 定义主窗口外观的 XAML 标记。 |
| **Views/MainWindow.axaml.cs** | 主窗口对应的代码隐藏文件。 |
| **Program.cs** | 应用程序入口点，负责配置并启动 Avalonia。 |
