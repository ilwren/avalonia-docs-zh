Avalonia 支持多款 IDE，挑一个最顺手的即可。

<Tabs groupId="ide">
  <TabItem value="vs" label="Visual Studio" default>

如果你在 Windows 上开发，[Visual Studio](https://visualstudio.microsoft.com/) 搭配 Avalonia for Visual Studio 扩展能带来相当完善的 XAML 编辑与预览体验。该扩展支持 Visual Studio 2022 17.12 及以上版本。

Avalonia for Visual Studio 扩展属于专业开发工具套件 [Avalonia Plus](https://avaloniaui.net/pricing) 的一部分。

安装 Avalonia for Visual Studio 的步骤：

1. 在 Visual Studio 中依次打开 **扩展 → 管理扩展**。
2. 在搜索栏中输入 “Avalonia”。
3. Click **Install**.
4. 按提示完成后续安装步骤。可能需要关闭并重新打开 Visual Studio 才能装好。

<Image light={DownloadAvaloniaExtensionForVS} alt="A screenshot displaying how to download the Avalonia extension in Visual Studio." position="center" maxWidth={400} cornerRadius="true" />

你也可以[从 Visual Studio Marketplace 下载该扩展](https://marketplace.visualstudio.com/items?itemName=AvaloniaTeam.AvaloniaVS)。

功能与设置的详细说明请见 [Avalonia for Visual Studio](/tools/visual-studio-extension) 页面。

:::note
如果你用的是较旧版本的 Visual Studio，可能需要从 Marketplace 下载对应的旧版扩展，例如 [2019 版](https://marketplace.visualstudio.com/items?itemName=AvaloniaTeam.AvaloniaforVisualStudio)。
:::

关于 XAML 预览器的更多说明，请参阅 [XAML 实时预览](/docs/app-development/xaml-preview-and-design-settings)。
  </TabItem>
  <TabItem value="vsc" label="Visual Studio Code">

[Avalonia for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=AvaloniaTeam.vscode-avalonia) 扩展与 Visual Studio 扩展基于同一套 XAML 解析器。两个 IDE 共用同一个底层引擎，因此每一项代码编辑方面的改进都会同时落地到 VS Code。

该扩展提供了相当完善的 IntelliSense：上下文感知的补全、完整的 `x:DataType` 快速信息、XAML 的「转到定义」、命名空间自动导入、事件处理程序生成、可直接采纳修复建议的诊断信息，以及一个 DPI 处理得当、运行稳定的内置 XAML 预览器。

安装 Avalonia for Visual Studio Code 的步骤：

1. 在 Visual Studio Code 中打开 **扩展** 视图（Ctrl+Shift+X）。
2. 在搜索栏中输入 “Avalonia”。
3. 找到由 “Avalonia Team” 发布的 **Avalonia for VSCode**，点击 **Install**。
4. 如有提示，重新加载 Visual Studio Code。

<Image light={DownloadAvaloniaExtensionForVsCode} alt="A screenshot displaying how to download the Avalonia extension in Visual Studio Code." position="center" maxWidth={400} cornerRadius="true" />

你也可以[从 Visual Studio Marketplace 下载该扩展](https://marketplace.visualstudio.com/items?itemName=AvaloniaTeam.vscode-avalonia)。

关于 XAML 预览器的更多说明，请参阅 [XAML 实时预览](/docs/app-development/xaml-preview-and-design-settings)。
  </TabItem>
  <TabItem value="rider" label="Rider">

如果你使用 macOS 或 Linux，推荐 [JetBrains Rider](https://www.jetbrains.com/rider/)。Rider 在这两个系统上提供了完整而成熟的开发体验，并且内置 XAML 支持。

建议再装一个第三方插件 [AvaloniaRider](https://plugins.jetbrains.com/plugin/14839-avaloniarider)，它能让你一边写 XAML 一边实时预览效果。

安装 AvaloniaRider 的步骤：

1. 在 JetBrains Rider 中依次打开 **Settings → Plugins**。
2. 切换到 **Marketplace** 选项卡。
3. 在搜索栏中输入 “AvaloniaRider”。
4. Click **Install**.
5. 按提示完成后续安装步骤。可能需要关闭并重新打开 JetBrains Rider 才能装好。

<Image light={DownloadAvaloniaRider} alt="A screenshot displaying how to download the AvaloniaRider extension in Rider." position="center" maxWidth={400} cornerRadius="true" />

关于 XAML 预览器的更多说明，请参阅 [XAML 实时预览](/docs/app-development/xaml-preview-and-design-settings)。
  </TabItem>
