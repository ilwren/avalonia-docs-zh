## 前置条件 {#prerequisites}

动手安装 Avalonia 之前，请先确认：

- **.NET 8.0 或更高版本**（截至 2025 年 10 月）

如果还没装 .NET，请到 [.NET 官网](https://dotnet.microsoft.com/en-us/download/dotnet) 下载，并按你所用操作系统的说明完成安装。

运行以下命令验证安装结果：

```bash
dotnet --version
```

输出的版本号应为 `8.0` 或更高。如果提示找不到该命令，请确认 .NET SDK 所在目录已加入系统 `PATH`。

:::tip[同时安装多个 .NET 版本]
你可以在同一台机器上安装多个 .NET SDK 版本。Avalonia 要求 .NET 8.0 或更高，但如有需要，项目仍可通过多目标框架编译到更早的版本。执行 `dotnet --list-sdks` 即可列出本机所有 SDK 版本。
:::

## 安装 Avalonia 模板 {#install-the-avalonia-templates}

Avalonia 使用标准的 .NET 模板来创建新项目。执行以下命令安装：

```bash
dotnet new install Avalonia.Templates
```

你应当看到模板安装成功的输出：

```text
Template Name                                 Short Name                  Language    Tags
--------------------------------------------  --------------------------  ----------  ---------------------------------------------------------
Avalonia .NET App                             avalonia.app                [C#],F#     Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia .NET MVVM App                        avalonia.mvvm               [C#],F#     Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia Cross Platform Application           avalonia.xplat              [C#],F#     Desktop/Xaml/Avalonia/Browser/Mobile
Avalonia Resource Dictionary                  avalonia.resource                       Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia Styles                               avalonia.styles                         Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia TemplatedControl                     avalonia.templatedcontrol   [C#],F#     Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia UserControl                          avalonia.usercontrol        [C#],F#     Desktop/Xaml/Avalonia/Windows/Linux/macOS
Avalonia Window                               avalonia.window             [C#],F#     Desktop/Xaml/Avalonia/Windows/Linux/macOS
```

想确认哪些模板已经装好，可以执行：

```bash
dotnet new list
```

在列表中找名字里带 “Avalonia” 的条目即可。

:::note
如果你用的是 Visual Studio，Avalonia for Visual Studio 扩展已经自带这些模板。只有在使用其他 IDE 或命令行时，才需要执行 `dotnet new install`。
:::

### 更新已安装的模板 {#update-existing-templates}

如果你之前装过这些模板，执行以下命令即可升级到最新版：

```bash
dotnet new update
```

该命令会更新所有已安装的模板包，其中也包括 `Avalonia.Templates`。若要安装特定版本的模板（例如与某个 Avalonia 发行版对齐），请显式指定版本号。

```bash
dotnet new install Avalonia.Templates@12.1.1
```

### 卸载模板 {#uninstall-templates}

如果你想移除 Avalonia 模板、从头再来，执行：

```bash
dotnet new uninstall Avalonia.Templates
```

然后用[上文提到的](#install-the-avalonia-templates) `dotnet new install` 命令重新安装。

## 验证安装 {#verify-the-installation}

创建一个小项目，确认一切正常：

```bash
dotnet new avalonia.app -o TestApp
cd TestApp
dotnet build
```

构建成功就说明安装没问题。确认完毕后，`TestApp` 文件夹可以直接删掉。

### 常见问题 {#common-issues}

- **`dotnet new` 列不出 Avalonia 模板。** 请确认你确实执行过 `dotnet new install Avalonia.Templates`，并且命令没有报错。重启终端后再试一次。
- **构建时报错，提示缺少 SDK。** 请确认 `dotnet --version` 输出的版本不低于 8.0。如果上层目录中有 `global.json` 文件把默认 SDK 锁定到了较旧的版本，请删除该文件，或将其改为要求一个兼容的 SDK 版本。
- **在 macOS 或 Linux 上遇到权限错误。** 如果安装命令因权限问题失败，请确认你没有加 `sudo`。.NET 模板引擎会把模板装进当前用户的配置目录，并不需要提权。

## 在已有的 .NET 项目中引入 Avalonia {#installing-avalonia-in-an-existing-net-project}

如果你要在一个已有的 .NET 项目（例如[类库](/docs/custom-controls/custom-control-library)）中引入 Avalonia，请使用所在 IDE 的 NuGet 包管理界面。

<Tabs groupId="ide">  
  <TabItem value="rider" label="Rider">
    1. 在解决方案面板中选中你的 .NET 项目。
    2. 点击 **Tools → NuGet → Manage NuGet Packages**。
    3. 在搜索栏中搜索 “Avalonia”。
    4. Select **Avalonia**.
    5. 选择需要的版本。
    6. 点击面板底部的项目名称，即可把 Avalonia 安装到该项目。

    <Image light={InstallAvaloniaInClassLibraryRider} alt="A screenshot demonstrating how to install the Avalonia NuGet package in Rider." position="center" maxWidth={400} cornerRadius="true"/>
  </TabItem>
  <TabItem value="vs" label="Visual Studio">
    1. 在解决方案资源管理器中选中你的 .NET 项目。
    2. 点击 **项目 → 管理 NuGet 程序包**。
    3. 切换到 **浏览** 选项卡，搜索 “Avalonia”。
    4. Select **Avalonia**.
    5. 选择需要的版本。
    6. Click **Install**.

    <Image light={InstallAvaloniaInClassLibraryVS} alt="A screenshot demonstrating how to install the Avalonia NuGet package in Visual Studio." position="center" maxWidth={400} cornerRadius="true"/>
  </TabItem>
  <TabItem value="vscode" label="VS Code">
    1. 打开命令面板：Windows 上按 <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>P</kbd>，macOS 上按 <kbd>Cmd</kbd> <kbd>⇧</kbd> <kbd>P</kbd>。
    2. 搜索并执行命令 **NuGet: Add NuGet Package**。
    3. 输入搜索词 “Avalonia” 并确认。
    4. 从搜索结果中选择 **Avalonia** 包。
    5. 选择需要的包版本即可完成安装。

    <Image light={InstallAvaloniaInClassLibraryVSCode} alt="A screenshot demonstrating how to install the Avalonia NuGet package in Visual Studio Code." position="center" maxWidth={400} cornerRadius="true"/>
  </TabItem>
</Tabs>
