## Avalonia 是什么？ {#what-is-avalonia}

Avalonia 是一个开源的 .NET 跨平台 UI 框架。它使用自研渲染引擎绘制控件，因此你的应用在每个平台上的外观和行为都完全一致。用 C# 或 F# 配合 XAML 写一次界面，就能发布到 Windows、macOS、Linux、iOS、Android 和 WebAssembly。

如果你用过 WPF 或 UWP，会发现 Avalonia 的 XAML 和 API 相当眼熟。如果你是第一次接触基于 XAML 的框架，那就从[入门教程](/docs/get-started/starter-tutorial)开始最合适。

## 已经装好 .NET 和 IDE 了？ {#already-have-net-and-an-ide}

如果 .NET 8+ 和 IDE 都已经就绪，可以直接跳到创建项目这一步：

```bash
dotnet new install Avalonia.Templates
dotnet new avalonia.mvvm -o MyApp
cd MyApp
dotnet run
```

## 从 WPF 转过来？ {#coming-from-wpf}

Avalonia 的 API 刻意向 WPF 看齐，但在样式、模板和属性系统上仍有一些重要差异。逐节对照可参阅 [WPF 迁移指南](/docs/migration/wpf)。

如果你需要让现有 WPF 应用在不重写的前提下跨平台运行，[Avalonia XPF](/xpf) 在 Avalonia 渲染引擎之上提供了二进制兼容的 WPF 支持。
