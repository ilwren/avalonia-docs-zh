## 使用 XAML 预览器 {#using-the-xaml-previewer}

下列环境提供 XAML 实时预览器：

- Visual Studio，需装 Avalonia for Visual Studio 扩展
- Visual Studio Code，需装 Avalonia for VSCode 扩展
- JetBrains Rider，需装第三方的 AvaloniaRider 插件

有了 XAML 预览器，你改 XAML 的同时就能看到效果，布局的变化立刻可见，不必重新构建项目。

:::note
XAML 预览器需要一个面向桌面平台的独立 Avalonia 可执行程序。跨平台类库或非桌面项目中的 XAML 文件在预览器里可能渲染不正确。若想预览这类文件，请把它们链接到桌面项目中。
:::

### 验证是否生效 {#checking-it-works}

1. 打开任意 **.axaml** 文件。本例用的是 Avalonia 默认模板里的 **MainWindow.axaml**。
2. 找到靠近文件底部的 `<TextBlock>...</TextBlock>` XAML 标签。
3. 删掉 `{Binding Greeting}`，换成任意文字，比如 "Nice preview!"。
4. 你边打字，预览窗格里就应该边出现这段文字。

## 设置设计时属性 {#setting-design-time-properties}

设计时属性只在 XAML 预览器中作用于你的 UI 控件，并不影响应用运行时的真实属性。用好它们，你调样式、调位置时就不用一遍遍构建应用了。

要使用设计时属性，必须先在 XAML 文件中加上一个命名空间：

```xml
xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
```

加好命名空间后，下列设计时属性就可以用了：
- `d:DesignWidth`
- `d:DesignHeight`
- `d:DataContext`

### DesignWidth 与 DesignHeight {#designwidth-and-designheight}

`d:DesignWidth` 和 `d:DesignHeight` 属性把指定的宽高套用到预览上。

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        d:DesignWidth="800" d:DesignHeight="450"
        x:Class="AvaloniaApplication1.MainWindow">
    Welcome to Avalonia!
</Window>
```

### DataContext

`d:DataContext` 属性为预览指定一个 `DataContext`。建议把它和 `{x:Static}` 指令配合使用，去引用程序集中的某个静态属性：

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:dd="clr-namespace:My.Namespace;assembly=MyAssembly"
        d:DataContext="{x:Static dd:DesignData.ExampleViewModel}"
        x:Class="AvaloniaApplication1.MainWindow">
    Welcome to Avalonia!
</Window>
```

```csharp
namespace My.Namespace
{
    public static class DesignData
    {
        public static MyViewModel ExampleViewModel { get; } = new MyViewModel
        {
            // View Model initialization here.
        };
    }
}
```

### Design.DataContext

除了 `d:DataContext`，你也可以使用 `Design.DataContext` 附加属性。

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:dd="clr-namespace:My.Namespace;assembly=MyAssembly"
        x:Class="AvaloniaApplication1.MainWindow"
        Design.Width="100">
    <Design.DataContext>
        <dd:MyViewModel />
    </Design.DataContext>
    Welcome to Avalonia!
</Window>
```

### 在代码中设置设计时 DataContext {#setting-the-design-time-datacontext-in-code}

上面介绍的几种设置设计时 `DataContext` 的办法，都假定视图模型有无参构造函数。但你的视图模型可能必须带参数构造，比如典型的[依赖注入模式](/docs/app-development/dependency-injection)。这种情况下可以用 `Design.SetDataContext` 方法去引用带参数的视图模型构造函数。

```csharp
public MainWindow()
{
    // Prevent the previewer's DataContext from being set when the application is run.
    if (Design.IsDesignMode)
    {
        // This can be before or after InitializeComponent.
        Design.SetDataContext(this, new MainWindowViewModel(new DialogService()));
    }
    InitializeComponent();
}
```

## 套用设计时数据 {#applying-design-time-data}

设计时数据会在 XAML 预览器中给界面填上模拟数据。和设计时属性一样，它让你不必反复构建应用、也不用调用数据服务层，就能打磨界面。

下面这个例子演示如何结合 MVVM 模式，用设计时数据做出一张预约卡片的界面。先看预约系统的基础功能。

```csharp
    // Data Properties
    public string ServerName { get; set; } = null!;
    public string ServiceTitle { get; set; } = null!;    
    public decimal ServicePrice { get; set; }
    public DateTime ServiceDateTime { get; set; }
    public string Description { get; set; } = null!;  
    
    // Commands
    private bool _isCancelVisible = true;

    public bool IsCancelVisible
    {
        get => _isCancelVisible;
        set => this.RaiseAndSetIfChanged(ref _isCancelVisible, value);
    }

    public ReactiveCommand<Unit, Unit> CancelAppointmentCommand =>
        ReactiveCommand.Create(() =>
        {
            IsCancelVisible = false;
        });

```

### 创建设计用视图模型 {#creating-the-design-view-model}

下一步是做一个设计版的视图模型。它装的是模拟数据，可供设计用的 [`DataContext`](#datacontext) 引用。

```csharp
public class DesignAppointmentViewModel: AppointmentViewModel
{
    public DesignAppointmentViewModel()
    {
        ServerName = "John Price";
        ServiceTitle = "Haircut and beard trim";
        ServicePrice = (decimal)25.5;
        ServiceDateTime = new DateTime(2023, 1, 3, 11, 15, 0);
        Description = "Please allow 30 minutes.";
    }
}
```

### 引用设计用视图模型 {#referencing-the-design-view-model}

接下来要引用上一节做好的设计用视图模型，好让它把模拟数据填进界面。

用编译型绑定（自 Avalonia 11 起为默认方式）的做法如下：

1. 在控件的 XAML 起始标签中加上 `xmlns:vm="using:AvaloniaApplication1.ViewModels"`，导入 `ViewModels` 命名空间。（示例里的 `AvaloniaApplication1` 请换成你自己的项目名。）
2. 还是在这个起始标签中，加上 `x:DataType="vm:DesignAppointmentViewModel"` 来声明 `ViewModel` 类，好让设计时环境能对类的属性做类型检查。

你的 XAML 文件大致应该长这样。
   
```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
             xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
             xmlns:vm="using:DesignTimeData.ViewModels"
             mc:Ignorable="d" d:DesignWidth="400" d:DesignHeight="250"
             x:Class="DesignTimeData.Views.AppointmentView"
             xmlns:vm="using:AvaloniaApplication1.ViewModels"
             x:DataType="vm:DesignAppointmentViewModel">
   
   <Design.DataContext>    
       <vm:DesignAppointmentViewModel/>
   </Design.DataContext>

</UserControl>
```

### 设计界面 {#designing-the-ui}

现在可以着手设计这张预约卡片的界面了。下面是一个示例界面。

```xml
<Border CornerRadius="10" Background="LightBlue"  Width="350" Margin="20">
  <DockPanel Width="350" >
      
    <StackPanel Height="10"
                    DockPanel.Dock="Bottom"
                    IsVisible="{Binding !IsCancelVisible, }" >
    </StackPanel>

    <Button Margin="0 10"
            HorizontalAlignment="Center"
            DockPanel.Dock="Bottom"
            ClickMode="Release"
            Command="{Binding CancelAppointmentCommand}"
            IsVisible="{Binding IsCancelVisible}">Cancel</Button>

    <StackPanel DockPanel.Dock="Left" Margin="10 10 0 0" Width="200" >
      <TextBlock Text="{Binding ServiceTitle}" FontWeight="Bold"/>
      <TextBlock Text="{Binding ServerName, StringFormat='with {0}'}"/>
      <TextBlock Margin="0 5 0 0" 
                 Text="{Binding ServiceDateTime, StringFormat={}{0:dd MMM yyyy}}"/>
      <TextBlock Text="{Binding ServiceDateTime, StringFormat={}{0:HH:mm}}"/>
      <TextBlock Margin="0 5" FontSize="20" 
                 Text="{Binding ServicePrice, StringFormat={}{0:£0.00}}"/>
      <TextBlock Text="{Binding Description, StringFormat={}{0:£0.00}}"/>
    </StackPanel>

    <Border DockPanel.Dock="Right"
      Background="Gainsboro" CornerRadius="10"
            Width="75" Height="75"
            Margin="0 20 20 0">
      <Image ToolTip.Tip="{Binding ServerName}" />
    </Border>

    <Rectangle/>

  </DockPanel>
</Border>
```
