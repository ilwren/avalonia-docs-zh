### RoundLayoutSizeUp 方法 {#roundlayoutsizeup-method}

Rounds a size to integer values for layout purposes, compensating for high DPI screen
coordinates by rounding the size up to the nearest pixel.

```csharp
public Avalonia.Size RoundLayoutSizeUp(Avalonia.Size size, double dpiScale)
```

#### 参数 {#parameters-8}

`size` [Avalonia.Size](xref:Avalonia.Size)

Input size.


`dpiScale` double

DPI 缩放系数。


#### 返回值 {#returns-7}

[Avalonia.Size](xref:Avalonia.Size)

Value of size that will be rounded under screen DPI.


#### 备注 {#remarks}

这是个布局辅助方法。它会把 DPI 考虑在内，并且当舍入结果对布局不可接受时
（比如 Infinity 或 NaN）不会返回该值。它与 UseLayoutRounding 属性配套，
不该拿来当作通用的取整工具。

</section>
