```csharp
public bool IsOpen { get; set; }
```

#### 备注 {#remarks}

Setting this property to `true` will show the flyout at the last known
placement target. If no target has been set via [Avalonia.Controls.Primitives.FlyoutBase.ShowAt(Avalonia.Controls.Control)](xref:Avalonia.Controls.Primitives.FlyoutBase.ShowAt%28Avalonia.Controls.Control%29),
setting this to `true` will have no effect.
