## 备注 {#remarks}

These failures are user-visible in effect — a shape the user drew does not appear, a delete
does nothing — so they are reported rather than logged and forgotten. Handle
[Avalonia.Controls.PdfViewer.AnnotationError](xref:Avalonia.Controls.PdfViewer.AnnotationError) to surface them in the host's own error UI.
