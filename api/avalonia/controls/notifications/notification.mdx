## 备注 {#remarks}

This class represents a notification that can be displayed either in a window using
[Avalonia.Controls.Notifications.WindowNotificationManager](xref:Avalonia.Controls.Notifications.WindowNotificationManager) or by the host operating system (to be implemented).
