### Copy 方法 {#copy-method}

把当前选区复制到剪贴板，不等待剪贴板写入完成。

```csharp
public void Copy()
```

#### 备注 {#remarks}

Await [Avalonia.Controls.Markdown.CopyAsync](xref:Avalonia.Controls.Markdown.CopyAsync) instead. The clipboard is a platform resource another
process can hold, so the write can fail after this method has already returned, and a
caller here can neither see that nor sequence anything after it.

</section>

### CopyAsync 方法 {#copyasync-method}

把当前选区复制到剪贴板。

```csharp
public System.Threading.Tasks.Task<bool> CopyAsync()
```

#### 返回值 {#returns-1}

System.Threading.Tasks.Task&lt;bool&gt;

when text reached the clipboard; when
there was nothing to copy, a [Avalonia.Controls.Markdown.CopyingToClipboard](xref:Avalonia.Controls.Markdown.CopyingToClipboard) handler took over, or
the control has no top level to read a clipboard from.


#### 备注 {#remarks-1}

Awaiting this surfaces a clipboard failure to the caller. A failure raised from a
fire-and-forget call reaches the synchronization context instead, where nothing can
handle it and the process goes down.

### AutoScrollToEnd 属性 {#autoscrolltoend-property}

Gets or sets whether the control automatically scrolls to the end
when new content is appended during a streaming session.

```csharp
public bool AutoScrollToEnd { get; set; }
```

#### 备注 {#remarks-4}

Uses sticky-bottom behavior: auto-scroll is active while the viewport
is at or near the bottom. If the user scrolls up, auto-scroll pauses
until the user scrolls back to the bottom.
