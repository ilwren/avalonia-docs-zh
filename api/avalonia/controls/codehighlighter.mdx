Derive from this to drive code blocks with your own lexer. The two shipped adapters,
`ColorCodeHighlighter` and `TextMateHighlighter`, are ordinary subclasses.
Attach one through [Avalonia.Controls.Markdown.CodeHighlighter](xref:Avalonia.Controls.Markdown.CodeHighlighter) for a whole control, or
through [Avalonia.Controls.Documents.MarkdownCodeBlock.Highlighter](xref:Avalonia.Controls.Documents.MarkdownCodeBlock.Highlighter) for a single block.
