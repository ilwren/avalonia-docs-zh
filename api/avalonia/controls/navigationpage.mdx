#### PopAllModalsAsync 方法 {#popallmodalsasync-method}

用 [Avalonia.Controls.NavigationPage.ModalTransition](xref:Avalonia.Controls.NavigationPage.ModalTransition) 弹出所有模态页面。

```csharp
public System.Threading.Tasks.Task PopAllModalsAsync()
```

##### 返回值 {#returns-9}

System.Threading.Tasks.Task


##### 备注 {#remarks-1}

All modals are dismissed in a single transition rather than one-by-one, so lifecycle
events differ from calling [Avalonia.Controls.NavigationPage.PopModalAsync](xref:Avalonia.Controls.NavigationPage.PopModalAsync) in a loop:

- [Avalonia.Controls.Page.Navigating](xref:Avalonia.Controls.Page.Navigating) is consulted only on the topmost modal. Intermediate modals do not receive a cancellation opportunity. If the top modal cancels, the entire dismiss is aborted and no modals are popped.
- [Avalonia.Controls.Page.NavigatedFrom](xref:Avalonia.Controls.Page.NavigatedFrom) fires on every dismissed modal in LIFO order.
- [Avalonia.Controls.Page.NavigatedTo](xref:Avalonia.Controls.Page.NavigatedTo) 只在 [Avalonia.Controls.Page.CurrentPage](xref:Avalonia.Controls.Page.CurrentPage) 上触发。
