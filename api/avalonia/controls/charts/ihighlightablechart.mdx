## 备注 {#remarks}

只有当图表确实有悬停高亮的渲染行为时才实现这份契约，
这样 [Avalonia.Controls.Charts.IHighlightableChart.IsHighlightEnabled](xref:Avalonia.Controls.Charts.IHighlightableChart.IsHighlightEnabled) 就不会出现在那些实现起来形同虚设的图表类型上。
