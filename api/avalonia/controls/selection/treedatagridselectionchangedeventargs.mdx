## 备注 {#remarks}

This is the unified base class for selection change events in [TreeDataGrid](xref:Avalonia.Controls.TreeDataGrid), used by both
row and cell selection models. It provides row-level indexes and items, as well as
cell-level indexes that expand rows across columns.

### DeselectedItems 属性 {#deselecteditems-property}

获取已从选区中移除的那些项。

```csharp
public System.Collections.Generic.IReadOnlyList<object> DeselectedItems { get; set; }
```

#### 备注 {#remarks-3}

When items are removed from the data source, their indexes are no longer valid but
the items themselves are still available in this collection as a concrete list that
remains valid regardless of later source modifications.

Otherwise (when items are deselected by a selection change) the items are resolved
lazily against the data source and must be read before the source collection is next
modified. Reading them after a modification (for example from an asynchronous or
dispatcher-queued handler) throws [InvalidOperationException](xref:System.InvalidOperationException).

</section>
