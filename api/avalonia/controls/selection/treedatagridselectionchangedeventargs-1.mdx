### DeselectedItems 属性 {#deselecteditems-property}

Gets the strongly-typed items that were removed from the selection.

```csharp
public System.Collections.Generic.IReadOnlyList<T> DeselectedItems { get; set; }
```

#### 备注 {#remarks-2}

When items are removed from the data source they are provided here as a concrete list
that remains valid regardless of later source modifications. Otherwise (when items are
deselected by a selection change) the items are resolved lazily against the data source
and must be read before the source collection is next modified. Reading them after a
modification (for example from an asynchronous or dispatcher-queued handler) throws
[InvalidOperationException](xref:System.InvalidOperationException).

</section>

#### 备注 {#remarks-4}

The items in this collection are resolved lazily against the data source, so they
must be read before the source collection is next modified. Reading them after a
modification (for example from an asynchronous or dispatcher-queued handler) throws
[InvalidOperationException](xref:System.InvalidOperationException). Use [Avalonia.Controls.Selection.TreeDataGridSelectionChangedEventArgs&lt;T&gt;.SelectedIndexes](xref:Avalonia.Controls.Selection.TreeDataGridSelectionChangedEventArgs%601.SelectedIndexes), which is
not affected, if you need to retain the change past a source modification.
