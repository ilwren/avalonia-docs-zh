## 备注 {#remarks}

[Avalonia.Controls.Selection.TreeDataGridRowSelectionModel&lt;T&gt;](xref:Avalonia.Controls.Selection.TreeDataGridRowSelectionModel%601) is generic, but the
[Avalonia.Controls.TreeDataGrid](xref:Avalonia.Controls.TreeDataGrid) and its automation peers need non-generic access to the row
selection state. Custom row selection models should implement this interface in order to
expose their selection to UI Automation clients such as screen readers, and to support
row drag/drop.

该接口尚属实验性：公开它是为了让你能实现自定义的选择模型，
但它在日后的版本中可能变动乃至移除。
