## 备注 {#remarks}

This event is raised when indexes in the selection model change due to insertions,
removals, or reordering in the underlying data source. It provides information
about which range of indexes was affected and how they were shifted.

#### 参数 {#parameters}

`parentIndex` [Avalonia.Controls.IndexPath](xref:Avalonia.Controls.IndexPath)

The index path of the parent item whose children were affected.


`startIndex` int

The index at which the change started.


`endIndex` int

The index at which the change ended.


`delta` int

The number of items added or removed.


#### 备注 {#remarks-1}

The `delta` parameter will be positive when items are added and
negative when items are removed.

The affected range is from `startIndex` (inclusive) to
`endIndex` (exclusive).

### Delta 属性 {#delta-property}

Gets the delta of the change; i.e. the number of indexes added or removed.

```csharp
public int Delta { get; set; }
```

#### 值 {#value}

A positive value indicates items were added; a negative value indicates items were
removed.


#### 备注 {#remarks-2}

When items are added, [Avalonia.Controls.Selection.TreeDataGridIndexesChangedEventArgs.Delta](xref:Avalonia.Controls.Selection.TreeDataGridIndexesChangedEventArgs.Delta) represents the number of items inserted.

When items are removed, [Avalonia.Controls.Selection.TreeDataGridIndexesChangedEventArgs.Delta](xref:Avalonia.Controls.Selection.TreeDataGridIndexesChangedEventArgs.Delta) is negative and its absolute value
represents the number of items removed. This value is used to adjust index paths that
point to items after the change.

</section>
