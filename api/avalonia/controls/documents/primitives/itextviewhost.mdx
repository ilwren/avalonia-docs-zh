## 备注 {#remarks}

This interface separates viewport management (which belongs to the host container like [RichTextEditor](xref:Avalonia.Controls.RichTextEditor))
from text rendering (which belongs to [ITextView](xref:Avalonia.Controls.Documents.Primitives.ITextView) / [TextViewBase](xref:Avalonia.Controls.Documents.Primitives.TextViewBase)).
Typically implemented by controls that contain a [ScrollViewer](xref:Avalonia.Controls.ScrollViewer) and a text view.
