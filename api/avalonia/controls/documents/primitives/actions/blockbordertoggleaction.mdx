## 备注 {#remarks}

它作用于选区覆盖的每一个块级元素。当段落位于 [Avalonia.Controls.Documents.TableCell](xref:Avalonia.Controls.Documents.TableCell) 中时，
优先取单元格而非内层段落，好让边框包住整个单元格；表格之外则以段落本身为目标。
文档为空时会实体化出一个隐式 Paragraph，这样用户在输入之前就能先加边框——
与文本输入以及其他块级操作遵循同样的约定。
