## 备注 {#remarks}

The replacement removes the old image node via
[Avalonia.Controls.Documents.TextModel.TextDocument.DeleteNode(Avalonia.Controls.Documents.TextModel.TextDocumentNode)](xref:Avalonia.Controls.Documents.TextModel.TextDocument.DeleteNode%28Avalonia.Controls.Documents.TextModel.TextDocumentNode%29) and inserts a fresh one at the same
position, so undo restores the original from immutable snapshot bytes rather
than a disposed [Avalonia.Controls.Documents.RichImage.Source](xref:Avalonia.Controls.Documents.RichImage.Source). A character-range delete of the
old image would leave a zero-length orphan node, so node deletion is used.
