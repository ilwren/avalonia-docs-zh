## 备注 {#remarks}

上标与下标互斥：两者切换的是同一个 [Avalonia.Controls.Documents.RichInline.BaselineAlignmentProperty](xref:Avalonia.Controls.Documents.RichInline.BaselineAlignmentProperty)，
因此启用其一会自动顶替另一个（模型/springload 键只有一个）。
所有切换、springload 与工具栏状态行为——包括插入符折叠停在已有下标 span 内时高亮点亮——
都继承自 [Avalonia.Controls.Documents.Primitives.Actions.FormattingToggleAction&lt;T&gt;](xref:Avalonia.Controls.Documents.Primitives.Actions.FormattingToggleAction%601)，与 Bold/Italic/Underline 走的是同一条路。
