## 备注 {#remarks}

它通过 [Avalonia.Controls.Documents.Primitives.Components.ClipboardOperations.TryGetPlainTextSnapshotAsync(Avalonia.Input.Platform.IClipboard,System.Threading.CancellationToken)](xref:Avalonia.Controls.Documents.Primitives.Components.ClipboardOperations.TryGetPlainTextSnapshotAsync%28Avalonia.Input.Platform.IClipboard%2CSystem.Threading.CancellationToken%29) 探查剪贴板：
若存在进程内的快照，则经 `PlainTextSerializer`（Serialize → Deserialize）降级处理，
从而让源文本与我们序列化器的输出完全一致；否则直接把平台的 `DataFormat.Text` 负载解析成快照。
得到的快照再通过 `TextRange.InsertSnapshot` 嫁接进去，
方式与 [Avalonia.Controls.Documents.Primitives.Actions.PasteAction](xref:Avalonia.Controls.Documents.Primitives.Actions.PasteAction) 插入富内容时相同。
