## 备注 {#remarks}

Block-level actions differ from inline actions in several ways:

- They operate on container elements (Block) rather than text runs ([RichInline](xref:Avalonia.Controls.Documents.RichInline))
- They can affect multiple blocks in a selection
- They need to handle mixed values when multiple blocks have different property values

Common block properties include:
[TextAlignment](xref:Avalonia.Media.TextAlignment), LineHeight, Margin, Padding, Background, BorderThickness, BorderBrush
