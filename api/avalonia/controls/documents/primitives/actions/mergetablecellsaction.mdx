## 备注 {#remarks}

被覆盖的单元格会向外扩成由完整单元格组成的最小矩形
（只要有部分重叠就把整个单元格纳入，与 Word 的做法一致）。
左上角那个单元格保留合并后的内容——按行优先顺序依次拼接——
并取得该矩形的跨列数与跨行数。
