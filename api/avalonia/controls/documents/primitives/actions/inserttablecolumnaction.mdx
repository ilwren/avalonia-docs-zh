## 备注 {#remarks}

Reachable as [Avalonia.Controls.Documents.Primitives.Actions.EditorActions.InsertColumnBefore](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActions.InsertColumnBefore) and
[Avalonia.Controls.Documents.Primitives.Actions.EditorActions.InsertColumnAfter](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActions.InsertColumnAfter). Each inserts a
[Avalonia.Controls.Documents.TableColumn](xref:Avalonia.Controls.Documents.TableColumn) and an empty [Avalonia.Controls.Documents.TableCell](xref:Avalonia.Controls.Documents.TableCell) in every row at the
corresponding index, keeping the table rectangular.
