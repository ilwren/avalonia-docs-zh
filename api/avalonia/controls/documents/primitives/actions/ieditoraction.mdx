## 备注 {#remarks}

Editor actions provide a unified abstraction for operations like formatting,
clipboard operations, and undo/redo. They can be used across multiple UI surfaces:
toolbar buttons, context menus, and keyboard shortcuts.

Actions are typically singletons accessed via the [Avalonia.Controls.Documents.Primitives.Actions.EditorActions](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActions) class.

### Gesture 属性 {#gesture-property}

Gets the optional keyboard gesture for this action.

```csharp
public Avalonia.Input.KeyGesture Gesture { get; set; }
```

#### 备注 {#remarks-6}

The gesture is what tooltips and menu items display. It registers nothing:
the shortcut that actually fires is handled by the editor's keyboard component,
so an action whose gesture differs from the one the editor handles advertises a
shortcut that does nothing.

### Id 属性 {#id-property}

Gets the unique identifier for this action.

```csharp
public string Id { get; set; }
```

#### 备注 {#remarks-7}

IDs follow a hierarchical naming convention:

- Edit.Undo, Edit.Redo, Edit.Cut, etc.
- Format.Bold, Format.Italic, etc.
- Block.TextAlignment.Left, List.ToggleBulletList, etc.
[Avalonia.Controls.Documents.Primitives.Actions.EditorActionIds](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActionIds) names the identifier of every built-in action.
