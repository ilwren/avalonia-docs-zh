## 备注 {#remarks}

This component works with [Avalonia.Controls.Documents.TextModel.TextDocument](xref:Avalonia.Controls.Documents.TextModel.TextDocument) and [Avalonia.Controls.TextSelection](xref:Avalonia.Controls.TextSelection),
using their [TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer) support for all operations.
The caret operations a subclass would need are internal, so the type is closed:
the constructor is internal and only this library derives from it. Add behaviour to
a view with an [Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent](xref:Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent) of your own, or a highlight layer.

#### 备注 {#remarks-2}

Await [Avalonia.Controls.Documents.Primitives.Components.TextViewKeyboard.CopyAsync(System.Threading.CancellationToken)](xref:Avalonia.Controls.Documents.Primitives.Components.TextViewKeyboard.CopyAsync%28System.Threading.CancellationToken%29) instead. The clipboard is a platform resource another
process can hold, so the write can fail after this method has already returned, and a
caller here can neither see that nor sequence anything after it.
