## 备注 {#remarks}

Text view components are modular pieces that handle specific interaction functionality
(keyboard navigation, mouse selection, caret rendering, etc.).

The host controls the lifecycle: components are registered via
[Avalonia.Controls.Documents.Primitives.IInteractiveTextHost.RegisterComponent(Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent)](xref:Avalonia.Controls.Documents.Primitives.IInteractiveTextHost.RegisterComponent%28Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent%29) and receive
[Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent.OnAttach(Avalonia.Controls.Documents.Primitives.IInteractiveTextHost)](xref:Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent.OnAttach%28Avalonia.Controls.Documents.Primitives.IInteractiveTextHost%29)/[Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent.OnDetach](xref:Avalonia.Controls.Documents.Primitives.Components.ITextViewComponent.OnDetach) callbacks when the host
activates or deactivates them.
