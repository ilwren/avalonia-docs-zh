## 备注 {#remarks}

Copy / cut publish the current selection as a single [Avalonia.Input.DataTransfer](xref:Avalonia.Input.DataTransfer) item
carrying both [Avalonia.Input.DataFormat.Text](xref:Avalonia.Input.DataFormat.Text) (eager, via
[Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer](xref:Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer)) and any rich format produced by the supplied
[Avalonia.Controls.Documents.Serialization.IDocumentSerializer](xref:Avalonia.Controls.Documents.Serialization.IDocumentSerializer)s. Rich payloads use the deferred
`DataTransferItem.Set` overload that takes a callback so they only run when a
consumer actually requests the format.

Paste probes the clipboard via
[Avalonia.Controls.Documents.Primitives.Components.ClipboardOperations.TryGetSnapshotAsync(Avalonia.Input.Platform.IClipboard,System.Collections.Generic.IReadOnlyList&#123;Avalonia.Controls.Documents.Serialization.IDocumentSerializer&#125;,System.Threading.CancellationToken)](xref:Avalonia.Controls.Documents.Primitives.Components.ClipboardOperations.TryGetSnapshotAsync%28Avalonia.Input.Platform.IClipboard%2CSystem.Collections.Generic.IReadOnlyList%7BAvalonia.Controls.Documents.Serialization.IDocumentSerializer%7D%2CSystem.Threading.CancellationToken%29)
for the richest format the editor can deserialize; plain text is the fallback.

### TryGetPlainTextSnapshotAsync 方法 {#trygetplaintextsnapshotasync-method}

#### 备注 {#remarks-1}

Probe order:

1. [Avalonia.Input.Platform.IClipboard.TryGetInProcessDataAsync](xref:Avalonia.Input.Platform.IClipboard.TryGetInProcessDataAsync) → [Avalonia.Controls.Documents.Primitives.Components.ClipboardFormats.InProcessSnapshot](xref:Avalonia.Controls.Documents.Primitives.Components.ClipboardFormats.InProcessSnapshot): when copy/paste happen within the same process, the rich snapshot is lowered through [Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer](xref:Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer) (Serialize→Deserialize) so the returned snapshot keeps the source text exactly as our serializer emits it but drops every formatting, list, and table structure.
2. Platform [Avalonia.Input.DataFormat.Text](xref:Avalonia.Input.DataFormat.Text) via [Avalonia.Input.Platform.IClipboard.TryGetDataAsync](xref:Avalonia.Input.Platform.IClipboard.TryGetDataAsync), fed to [Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer.Deserialize(string)](xref:Avalonia.Controls.Documents.Serialization.PlainText.PlainTextSerializer.Deserialize%28System.String%29).

Rich formats (RTF, etc.) are intentionally not probed — by convention,
every producer that publishes RTF also publishes `DataFormat.Text`
next to it.
