## 备注 {#remarks}

Subclasses decorate realized [Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode](xref:Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode) instances
without modifying the block data model. A single adorner can provide
immediate-mode rendering via [Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.Render(Avalonia.Media.DrawingContext,Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode,Avalonia.Rect)](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.Render%28Avalonia.Media.DrawingContext%2CAvalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode%2CAvalonia.Rect%29), interactive controls
via [Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.CreateControl(Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode)](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.CreateControl%28Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode%29)/[Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.UpdateControl(Avalonia.Controls.Control,Avalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode,Avalonia.Rect)](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.UpdateControl%28Avalonia.Controls.Control%2CAvalonia.Controls.Documents.Primitives.DocumentNodes.DocumentNode%2CAvalonia.Rect%29), or both.

Each adorner declares which block categories it targets via
[Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.TargetAreas](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.TargetAreas) and whether it renders on all matching blocks
or only the current context block via [Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.Visibility](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner.Visibility).

Because [Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdorner) extends [Avalonia.StyledElement](xref:Avalonia.StyledElement),
adorners added to a [Avalonia.Controls.Documents.Primitives.Adorners.BlockAdornerLayer](xref:Avalonia.Controls.Documents.Primitives.Adorners.BlockAdornerLayer) join its logical
tree and can receive styles and dynamic resources from ancestor
resource dictionaries.
