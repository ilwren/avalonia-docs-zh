### GetPositionAtLineX 方法 {#getpositionatlinex-method}

Returns the text position on `line` closest to the
specified X coordinate. The result is guaranteed to stay on
`line`; it never crosses into a neighbouring line
or block, regardless of how far `x` lies outside
the line's horizontal bounds.

```csharp
public Avalonia.Controls.Documents.TextModel.TextPointer GetPositionAtLineX(Avalonia.Controls.Documents.Primitives.ITextLine line, double x)
```

#### 参数 {#parameters-4}

`line` [Avalonia.Controls.Documents.Primitives.ITextLine](xref:Avalonia.Controls.Documents.Primitives.ITextLine)

The target line.


`x` double

The desired X coordinate in view space.


#### 返回值 {#returns-4}

[Avalonia.Controls.Documents.TextModel.TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer)

A node-aware pointer on `line`, or `null`
when the line or its containing element cannot be resolved.


#### 备注 {#remarks-1}

This is the structure-first primitive used by vertical caret
navigation. It avoids the offset collisions that affect empty
paragraphs and prevents the hit test from leaking into adjacent
blocks when `x` is near a block boundary.

#### 备注 {#remarks-3}

In a virtualizing view, [Avalonia.Controls.Documents.Primitives.ITextView.GetLineFromPosition(Avalonia.Controls.Documents.TextModel.TextPointer)](xref:Avalonia.Controls.Documents.Primitives.ITextView.GetLineFromPosition%28Avalonia.Controls.Documents.TextModel.TextPointer%29) returns `null`
when the target block is not realized. This method skips over unrealized
blocks and returns the first line that the view can resolve. Non-virtualizing
implementations may simply delegate to [Avalonia.Controls.Documents.Primitives.ITextView.GetLineFromPosition(Avalonia.Controls.Documents.TextModel.TextPointer)](xref:Avalonia.Controls.Documents.Primitives.ITextView.GetLineFromPosition%28Avalonia.Controls.Documents.TextModel.TextPointer%29).
