## 备注 {#remarks}

This interface provides everything a read-only interactive view needs:
document access, selection, component registration, and input scope.
Read-only controls like `Markdown` and `FlowDocumentScrollViewer`
implement this interface directly.

For editing support (text insertion, deletion, formatting), see
`ITextEditorHost` which extends this interface with
editing-specific members.

### ActiveDocumentChanged 事件 {#activedocumentchanged-event}

Occurs when [Avalonia.Controls.Documents.Primitives.IInteractiveTextHost.ActiveDocument](xref:Avalonia.Controls.Documents.Primitives.IInteractiveTextHost.ActiveDocument) changes: the selection entered a page
band or a footnote, or returned to the main document. A host without nested
documents never raises it, but must still declare it - a component that follows
the caret across documents has no other way to learn of the move, because a
pure activation carries no selection change.

```csharp
public event EventHandler ActiveDocumentChanged
```

#### 备注 {#remarks-4}

Defaults to a no-op so a host written before this member existed still compiles. Such a
host has no nested documents to move between, so there is nothing for it to raise.
