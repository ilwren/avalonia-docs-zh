## 备注 {#remarks}

The font list is sourced from the bound [Avalonia.Controls.Documents.Primitives.Toolbar.EditorMenuItem.Action](xref:Avalonia.Controls.Documents.Primitives.Toolbar.EditorMenuItem.Action)
when it implements [Avalonia.Controls.Documents.Primitives.Actions.IPropertyAction](xref:Avalonia.Controls.Documents.Primitives.Actions.IPropertyAction). Each child
[Avalonia.Controls.Documents.Primitives.Toolbar.EditorMenuItem](xref:Avalonia.Controls.Documents.Primitives.Toolbar.EditorMenuItem) sets `FontFamily` on its header so the
user sees a live preview of the typeface in the overflow menu.
Use this as the [Avalonia.Controls.Documents.Primitives.Toolbar.EditorTool.OverflowMenuItem](xref:Avalonia.Controls.Documents.Primitives.Toolbar.EditorTool.OverflowMenuItem) for the
font family [Avalonia.Controls.Documents.Primitives.Toolbar.ComboBoxTool](xref:Avalonia.Controls.Documents.Primitives.Toolbar.ComboBoxTool).
