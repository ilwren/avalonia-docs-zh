### Unit 属性 {#unit-property}

The unit being built (or replayed) by this scope. For empty scopes
(undo disabled or replay in progress) this returns the
[Avalonia.Controls.Documents.Undo.EmptyUndoUnit](xref:Avalonia.Controls.Documents.Undo.EmptyUndoUnit) sentinel — never
— so consumers can read [Avalonia.Controls.Documents.Undo.IUndoUnit.Description](xref:Avalonia.Controls.Documents.Undo.IUndoUnit.Description) without
a null check. The
[Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.UndoUnit](xref:Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.UndoUnit) property,
in contrast, is for scopes that did not open
a real unit, preserving a distinct semantic.
