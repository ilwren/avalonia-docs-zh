## 备注 {#remarks}

[Avalonia.Controls.Documents.Undo.UndoManager](xref:Avalonia.Controls.Documents.Undo.UndoManager) is the only implementation, and the one a document creates for
itself. Prefer that type where you can name it: an abstraction with a single
implementation buys nothing, and [Avalonia.Controls.Documents.Undo.IUndoManager.Record(Avalonia.Controls.Documents.Undo.IUndoUnit)](xref:Avalonia.Controls.Documents.Undo.IUndoManager.Record%28Avalonia.Controls.Documents.Undo.IUndoUnit%29) in particular cannot be satisfied
from outside this assembly.
