## 备注 {#remarks}

Memory footprint: ~8 bytes per instance (struct, inline in [SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode)).

Only relevant for list nodes. Null properties mean "not explicitly set, inherit from parent or use default".

This struct contains only format-independent properties that map directly to UI counterparts.
RTF-specific measurements (marker indent, text indent, etc.) are stored in BlockRtfMetadata.
