## 备注 {#remarks}

Captures the inheritable visual properties that every [Avalonia.Controls.Documents.RichTextElement](xref:Avalonia.Controls.Documents.RichTextElement)
can carry: font family/size/weight/style/stretch, foreground, background,
letter spacing, and font features. [Avalonia.Controls.Documents.TextModel.Formatting.InlineFormatting](xref:Avalonia.Controls.Documents.TextModel.Formatting.InlineFormatting) and
[Avalonia.Controls.Documents.TextModel.Formatting.BlockFormatting](xref:Avalonia.Controls.Documents.TextModel.Formatting.BlockFormatting) carry only what is specific to them.

Stored on [Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode) so every snapshot node (inline, block,
table-row, image, etc.) can carry base-level formatting without type-specific
snapshot subclasses.

#### 备注 {#remarks-1}

Do not write through this array. A snapshot is read by a serializer running on
another thread while the document carries on being edited, and the array is handed
out by reference, so a write here is a write the reader may see halfway through.
Build a new array and assign it instead.
