## 备注 {#remarks}

Memory footprint: ~8 bytes + array overhead (struct, inline in [SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode)).

Only relevant for table nodes. Null properties mean "not explicitly set, inherit from parent or use default".

Format-agnostic: Contains only primitive values in device-independent pixels (DIPs).
Format-specific details (RTF cell spacing/padding, border styles, cell merge flags, etc.)
are stored in format-specific metadata (e.g., TableRtfMetadata).

Properties are optimized for extraction from [RichTextElement](xref:Avalonia.Controls.Documents.RichTextElement) during snapshot creation
and reconstruction to [RichTextElement](xref:Avalonia.Controls.Documents.RichTextElement) from snapshot. Values use device-independent pixels
to match Avalonia property system conventions.

Cell padding maps to `TableCell.Padding`, with the original RTF values (\trgaph) preserved in TableRtfMetadata for round-trip.

#### 备注 {#remarks-1}

The widths carry their [Avalonia.Controls.GridUnitType](xref:Avalonia.Controls.GridUnitType), so a Star column stays a
Star column across snapshot capture, undo and a serializer round trip. The
array is immutable: these widths reach undo and redo through
`TableSnapshotNode`, where a write through an alias would rewrite a
recorded state.
