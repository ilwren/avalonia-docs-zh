## 备注 {#remarks}

Base-level properties (font, foreground, background, letter spacing) are stored
in [Avalonia.Controls.Documents.TextModel.Formatting.TextElementFormatting](xref:Avalonia.Controls.Documents.TextModel.Formatting.TextElementFormatting) on the [Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode).
This struct holds the remaining inline-only properties: text decorations
and baseline alignment.
