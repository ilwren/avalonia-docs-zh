## 备注 {#remarks}

Contains format-agnostic page-level properties that apply to the entire document.
Format-specific details (header/footer margins, gutter, etc.) are stored
in format-specific metadata on the root [Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode).

All measurements are in device-independent pixels (DIPs) to match Avalonia conventions.

### PageBandDistance 属性 {#pagebanddistance-property}

Distance from the sheet edge to a page band in device-independent pixels: the
header's top sits this far below the sheet top, the footer's bottom this far
above the sheet bottom. Null means the document declares none and
[Avalonia.Controls.Documents.PageBandPolicy.DefaultDistance](xref:Avalonia.Controls.Documents.PageBandPolicy.DefaultDistance) applies. Maps to DOCX
`w:pgMar/@w:header` and `@w:footer` and to RTF `\headery` and
`\footery`.

```csharp
public Nullable<double> PageBandDistance { get; set; }
```

#### 备注 {#remarks-1}

A band taller than the space this leaves pushes the body down, so the value
decides where pages break. Screen, print and PDF all read it from here: a
distance held by a view would break the same document on different lines.
