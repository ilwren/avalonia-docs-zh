## 备注 {#remarks}

`StaticTextPointer` is 8 bytes (int + enum), stack-allocated, and
requires zero heap allocations. It is the value-type counterpart
to the full [Avalonia.Controls.Documents.TextModel.TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer) class, following the same
dual pattern as WPF's [StaticTextPointer](xref:Avalonia.Controls.Documents.TextModel.StaticTextPointer) / [TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer).

This type intentionally does not carry a node reference. To obtain a
node-aware [Avalonia.Controls.Documents.TextModel.TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer), use the containing element's
`ContentStart` / `ContentEnd` properties on
`ITextLine.ContainingElement` instead of converting
from offset alone, which cannot disambiguate between consecutive
zero-length blocks that share the same offset.
