## 备注 {#remarks}

One [Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs](xref:Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs) aggregates every
[Avalonia.Controls.Documents.TextModel.TextChangeEventArgs](xref:Avalonia.Controls.Documents.TextModel.TextChangeEventArgs) that fired in the same scope, in
invocation order. The aggregate is the right hook for batch-aware
consumers (autosave, replication, status updates); per-edit consumers
can keep using [Avalonia.Controls.Documents.TextModel.TextDocument.TextChanged](xref:Avalonia.Controls.Documents.TextModel.TextDocument.TextChanged).

[Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.Origin](xref:Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.Origin) and [Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.UndoUnit](xref:Avalonia.Controls.Documents.TextModel.DocumentChangedEventArgs.UndoUnit) let consumers correlate
the commit with the undo/redo system. See the [Avalonia.Controls.Documents.TextModel.ChangeOrigin](xref:Avalonia.Controls.Documents.TextModel.ChangeOrigin)
documentation for the four scenarios.
