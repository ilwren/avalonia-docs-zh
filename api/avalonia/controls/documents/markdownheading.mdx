A [Avalonia.Controls.Documents.Paragraph](xref:Avalonia.Controls.Documents.Paragraph) that represents a markdown heading (H1-H6).
Carries the heading level as a typed property so it survives element
realization and is authorable through the [FlowDocument](xref:Avalonia.Controls.Documents.FlowDocument) API; the
"header" / "h&#123;level&#125;" CSS classes remain the styling surface.
