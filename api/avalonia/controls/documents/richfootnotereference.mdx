<div className="apiref-page__lead">

A footnote anchor: an inline that marks where a note attaches to the text and
shows the note's number. Nothing numeric is stored: the anchor occupies a single
object replacement character, the convention an embedded object uses, and
rendering resolves the number from the anchor's position - the 1-based index of
its note among the document's [Avalonia.Controls.Documents.FlowDocument.Footnotes](xref:Avalonia.Controls.Documents.FlowDocument.Footnotes), which the
document keeps in anchor order. The anchor edits as one atomic unit.
[Avalonia.Controls.Documents.RichFootnoteReference.NoteId](xref:Avalonia.Controls.Documents.RichFootnoteReference.NoteId) pairs the anchor with its [Avalonia.Controls.Documents.Footnote](xref:Avalonia.Controls.Documents.Footnote) body -
deleting the anchor deletes the note, and moving an anchor moves its note with
it, so the numbers follow every edit without touching the text.
