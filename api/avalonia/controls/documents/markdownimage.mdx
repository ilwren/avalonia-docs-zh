## 备注 {#remarks}

An image takes the [Avalonia.Controls.Markdown.ImageLoader](xref:Avalonia.Controls.Markdown.ImageLoader) its containing control supplies
unless [Avalonia.Controls.Documents.MarkdownImage.ImageLoader](xref:Avalonia.Controls.Documents.MarkdownImage.ImageLoader) gives it one of its own, mirroring how
[Avalonia.Controls.Documents.MarkdownCodeBlock.Highlighter](xref:Avalonia.Controls.Documents.MarkdownCodeBlock.Highlighter) resolves.
Setting [Avalonia.Controls.Documents.MarkdownImage.ImageSource](xref:Avalonia.Controls.Documents.MarkdownImage.ImageSource) establishes a deferred image source on the
base [Avalonia.Controls.Documents.RichImage](xref:Avalonia.Controls.Documents.RichImage); the shared `ImagePresenter` resolves it
through the loader (network/file) only when the image is rendered.
