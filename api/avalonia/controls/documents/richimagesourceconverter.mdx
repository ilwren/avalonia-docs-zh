## 备注 {#remarks}

相对 URI 会相对于正在加载文档的 XAML 基 URI 解析，与 [Avalonia.Media.FontFamily](xref:Avalonia.Media.FontFamily) 和 Avalonia 的 `Image.Source`
解析相对资产引用的方式一致。本地资产（经资产加载器的 `avares:`/`resm:`，或来自磁盘的 `file:`）
会被立即读入并以 [Avalonia.Controls.Documents.EmbeddedImageSource](xref:Avalonia.Controls.Documents.EmbeddedImageSource) 的形式内嵌，这样像素数据便随文档一起走、一起序列化。
远程图像（`http:`/`https:`）则变成记录了该 URL 的 [Avalonia.Controls.Documents.DeferredImageSource](xref:Avalonia.Controls.Documents.DeferredImageSource)；在加载器解析出来之前，
编辑器会先显示一个占位图。MIME 类型由文件扩展名推断。
