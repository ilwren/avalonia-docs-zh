<div className="apiref-page__lead">

The footnotes a document owns, as elements, in anchor order: a view over the text
document's [Avalonia.Controls.Documents.TextModel.TextDocument.Footnotes](xref:Avalonia.Controls.Documents.TextModel.TextDocument.Footnotes), which owns the notes, materializing
a [Avalonia.Controls.Documents.Footnote](xref:Avalonia.Controls.Documents.Footnote) element per note on demand. It follows the contract of the
block collection: the document becomes a note's logical parent the moment it is
added; while the document has no text document the note waits pending, and it
joins the text document when that is initialized, before the pending blocks
materialize; once the text document exists a note joins it at once. Under the
anchor-owns-its-note lifecycle the notes come and go with their anchors; a note
added here pairs with the anchor carrying its id, or waits for one. Ownership is
exclusive, and a nested document (a page band, a note) owns no notes.
