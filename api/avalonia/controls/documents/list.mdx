### MarkerAlignment 属性 {#markeralignment-property}

Gets or sets how the marker is aligned within its column (Word's `w:lvlJc`).
[Avalonia.Media.TextAlignment.Left](xref:Avalonia.Media.TextAlignment.Left) starts every marker at the same x;
[Avalonia.Media.TextAlignment.Right](xref:Avalonia.Media.TextAlignment.Right) ends every marker at the same x with a consistent
gap to the content, matching how Word aligns e.g. roman-numeral markers. The
property default is [Avalonia.Media.TextAlignment.Left](xref:Avalonia.Media.TextAlignment.Left), but a list that never sets it
renders numbered markers right-aligned and bullets left-aligned by convention.
