## 备注 {#remarks}

A reader that knows a run's whole chain up front - an innermost run inside bold inside
underline, say - describes it as a span of these and pays nothing to describe it: the
builder reads the span and constructs the snapshot nodes directly, where the draft path
allocates a draft object, a child list, and that list's backing array per level.
