## 备注 {#remarks}

Names and values are spans into the tag text the tokenizer is currently holding, so reading
them allocates nothing. The spans are only valid for the duration of the handler callback;
call [ReadOnlySpan&lt;T&gt;.ToString](xref:System.ReadOnlySpan%601.ToString) on anything that has to outlive it.
