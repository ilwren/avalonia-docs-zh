## 备注 {#remarks}

This enum replaces the former per-format `SpacingExportMode` and
`Preserve*` boolean options with a single axis that determines both the
control-word strategy and custom-marker behavior.

## 字段 {#fields}

| 名称 | 说明 |
| --- | --- |
| [InteropSafe](#uid-8f846af08b) | Native, broadly interoperable controls understood by external editors. Custom ignorable markers are still emitted for properties that have no native representation, preserving round-trip fidelity for internal re-import. |
| [Portable](#uid-9bdc3e00bf) | Maximum portability. Uses only native controls and omits all custom serializer markers. Suitable for export to external consumers that will never be re-imported. Some formatting may be lost. |
| [RoundTripStrict](#uid-64aeaa688d) | Maximum internal round-trip fidelity. Emits synthetic controls (e.g., zero-width borders with `\brsp` spacing) and all custom ignorable markers (`{\*\acdpad}`, `acd:*` attributes). External editors may strip or misinterpret these controls. |
