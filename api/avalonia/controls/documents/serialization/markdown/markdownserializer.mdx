## 备注 {#remarks}

Round-trip contract: documents whose content came from markdown (or was
authored with the markdown-specific elements) re-parse to an equivalent
snapshot after writing; discrete authoring data (heading levels, code
languages, alert kinds, checked states, URLs, titles, alt text, footnote
labels, table alignment) is preserved exactly, while syntax spellings the
model does not store (emphasis delimiters, bullet chars, fence chars) are
written in the canonical form configured by [Avalonia.Controls.Documents.Serialization.Markdown.MarkdownSerializer.Options](xref:Avalonia.Controls.Documents.Serialization.Markdown.MarkdownSerializer.Options).
Foreign documents (RTF-loaded, arbitrary FlowDocuments) serialize as
canonical markdown of whatever structure maps; unmappable formatting is
dropped.

This serializer is thread-safe for concurrent operations: its options and
pipeline are fixed at construction.

Cancellation is observed per block while a document is rendered or written.
The Markdig parse that precedes rendering runs to completion once entered,
so a token cancelled during it takes effect at the next block.
