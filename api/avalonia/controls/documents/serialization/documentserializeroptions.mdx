## 备注 {#remarks}

Replaces the former per-format `RtfSerializerOptions` and `DocxSerializerOptions`
with a single type. All serializer behavior is derived from [Avalonia.Controls.Documents.Serialization.DocumentSerializerOptions.ExportMode](xref:Avalonia.Controls.Documents.Serialization.DocumentSerializerOptions.ExportMode):

- [Avalonia.Controls.Documents.Serialization.DocumentExportMode.RoundTripStrict](xref:Avalonia.Controls.Documents.Serialization.DocumentExportMode.RoundTripStrict): synthetic controls + all custom markers.
- [Avalonia.Controls.Documents.Serialization.DocumentExportMode.InteropSafe](xref:Avalonia.Controls.Documents.Serialization.DocumentExportMode.InteropSafe): native controls + custom markers for unsupported properties.
- [Avalonia.Controls.Documents.Serialization.DocumentExportMode.Portable](xref:Avalonia.Controls.Documents.Serialization.DocumentExportMode.Portable): native controls only, no custom markers.

### MaxImageBytes 属性 {#maximagebytes-property}

Maximum size, in bytes, of a single embedded image. An image whose payload exceeds
this limit is skipped and the surrounding document still loads.
(the default) imposes no limit. Use this to guard against
hostile or malformed documents with oversized image payloads.

```csharp
public Nullable<long> MaxImageBytes { get; set; }
```

#### 备注 {#remarks-1}

Applies to every format that carries image bytes: on read to RTF, DOCX, XAML and
HTML, and on write to PDF, where the payload measured is the sample buffer for an
image that holds only pixels. Plain text and Markdown carry no embedded images -
a Markdown image is always a reference the host resolves - so the limit does not
reach them.
