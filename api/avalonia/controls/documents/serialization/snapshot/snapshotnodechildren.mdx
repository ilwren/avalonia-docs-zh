#### 参数 {#parameters}

`count` int

How many leading entries are in use.


#### 备注 {#remarks}

The array is stored by reference, so a later write to it changes an object
the rest of the surface presents as immutable. Building a snapshot tree goes
through [Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshotBuilder](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshotBuilder), which owns its arrays;
[Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNodeChildren.Empty](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNodeChildren.Empty) is the only instance a caller outside the assembly needs
to name.
