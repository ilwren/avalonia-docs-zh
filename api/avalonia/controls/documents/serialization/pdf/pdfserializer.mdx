## 备注 {#remarks}

PDF is an export-only format for this library: [Avalonia.Controls.Documents.Serialization.Pdf.PdfSerializer.Deserialize(System.IO.Stream,System.Threading.CancellationToken)](xref:Avalonia.Controls.Documents.Serialization.Pdf.PdfSerializer.Deserialize%28System.IO.Stream%2CSystem.Threading.CancellationToken%29) always throws
[NotSupportedException](xref:System.NotSupportedException) and [Avalonia.Controls.Documents.Serialization.Pdf.PdfSerializer.CanDeserialize(System.IO.Stream)](xref:Avalonia.Controls.Documents.Serialization.Pdf.PdfSerializer.CanDeserialize%28System.IO.Stream%29) always returns
.

The exporter is UI-free. It consumes the [Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot) directly and never
creates controls or requires a dispatcher, so serialization can run on any thread. It does
require an initialized Avalonia platform (font manager and text shaper) once content layout
is involved; a bare console process without Avalonia cannot export.

This serializer is thread-safe for concurrent operations.
