### ContentStart 属性 {#contentstart-property}

Gets a text pointer to the start of the content in the document.

```csharp
public Avalonia.Controls.Documents.TextModel.TextPointer ContentStart { get; set; }
```

#### 备注 {#remarks-1}

If the element is not attached to a document, returns null.

Returns the element's cached pointer instance, not a fresh
allocation. Callers that store the result in a mutable container
(e.g. [Avalonia.Controls.Documents.TextModel.TextRange](xref:Avalonia.Controls.Documents.TextModel.TextRange) endpoints, undo records) must
call [Avalonia.Controls.Documents.TextModel.TextPointer.Clone](xref:Avalonia.Controls.Documents.TextModel.TextPointer.Clone) first; otherwise a later
`UpdateInPlace`/`Refresh` through that container will
shift the element's cached origin pointer and corrupt every
future [Avalonia.Controls.Documents.RichTextElement.ContentStart](xref:Avalonia.Controls.Documents.RichTextElement.ContentStart)/[Avalonia.Controls.Documents.RichTextElement.ContentRange](xref:Avalonia.Controls.Documents.RichTextElement.ContentRange)
read at the current generation. [Avalonia.Controls.Documents.TextModel.TextRange](xref:Avalonia.Controls.Documents.TextModel.TextRange)'s
constructors and `SetPositions` already perform this clone
automatically.

</section>
