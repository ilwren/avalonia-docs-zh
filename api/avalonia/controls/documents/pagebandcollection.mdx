<div className="apiref-page__lead">

文档所拥有的页面带状区域，以元素形式给出：它是文本文档 [Avalonia.Controls.Documents.TextModel.TextDocument.PageBands](xref:Avalonia.Controls.Documents.TextModel.TextDocument.PageBands) 的一个视图，
真正持有这些带状区域的是后者，这里按需为每个带状区域实体化出一个 [Avalonia.Controls.Documents.PageBand](xref:Avalonia.Controls.Documents.PageBand) 元素。
它遵循块集合的约定：带状区域一加入，文档便成为它的逻辑父级；文档尚无文本文档时，
带状区域处于待定状态，待文本文档初始化后便加入其中——这发生在待定的块实体化之前；
文本文档已存在时，带状区域则立即加入。移除某个带状区域会一并解除其所有者、逻辑父级
与撤销关联，并清除所有指向它的 section 引用。所有权是独占的：已归属其他文档的带状区域，
在从那边移除之前不会被接纳。某个角色与规则下的第一个带状区域，就是该规则所摆放的那一个。
