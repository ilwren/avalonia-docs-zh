### BringIntoViewOnFocusChange 属性 {#bringintoviewonfocuschange-property}

Gets or sets a value that determines whether the [Avalonia.Controls.ScrollViewer](xref:Avalonia.Controls.ScrollViewer) uses a
bring-into-view scroll behavior when an item in the view gets focus.

```csharp
public bool BringIntoViewOnFocusChange { get; set; }
```

#### 值 {#value}

true to use a behavior that brings focused items into view. false to use a behavior
that focused items do not automatically scroll into view. The default is true.


#### 备注 {#remarks-2}

[Avalonia.Controls.ScrollViewer.BringIntoViewOnFocusChange](xref:Avalonia.Controls.ScrollViewer.BringIntoViewOnFocusChange) can either be set explicitly on a
[Avalonia.Controls.ScrollViewer](xref:Avalonia.Controls.ScrollViewer), or a the attached

```csharp
ScrollViewer.BringIntoViewOnFocusChange
```
property can be set on an element
that hosts a [Avalonia.Controls.ScrollViewer](xref:Avalonia.Controls.ScrollViewer).
