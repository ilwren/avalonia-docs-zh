## 备注 {#remarks}

This attribute is used to configure markup extensions like [TemplateBinding](xref:Avalonia.Data.TemplateBinding) to properly parse [AvaloniaProperty](xref:Avalonia.AvaloniaProperty) values,
targeting a specific scope data type.
