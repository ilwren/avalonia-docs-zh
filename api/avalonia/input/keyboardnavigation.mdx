#### 备注 {#remarks-2}

When focus enters a container which has its [Avalonia.Input.KeyboardNavigation.TabNavigationProperty](xref:Avalonia.Input.KeyboardNavigation.TabNavigationProperty)

defines to which child the focus should move.
