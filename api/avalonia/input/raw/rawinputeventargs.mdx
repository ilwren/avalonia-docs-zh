## 备注 {#remarks}

原始输入事件由窗口子系统发给 [Avalonia.Input.InputManager](xref:Avalonia.Input.InputManager) 处理，
这给了应用预处理这些事件的机会。预处理之后，它们被相应的 [Avalonia.Input.Raw.RawInputEventArgs.Device](xref:Avalonia.Input.Raw.RawInputEventArgs.Device) 消费，
并转成标准的 Avalonia 事件。
