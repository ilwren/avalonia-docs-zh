### FormatKey 方法 {#formatkey-method}

Checks the platformKeyOverrides and s_commonKeyOverrides Dictionaries, in order, for the appropriate
string to represent the given Key on this platform.
NOTE: If platformKeyOverrides is null, this is assumed to be the Invariant and the Dictionaries are not checked.
The plain Enum string is returned instead.

```csharp
public string FormatKey(Avalonia.Input.Key key)
```

#### 参数 {#parameters-1}

`key` [Avalonia.Input.Key](xref:Avalonia.Input.Key)

The Key to format.


#### 返回值 {#returns}

string

The appropriate platform specific or common override if present, key.ToString() if not or this is the Invariant.

### GetInstance 方法 {#getinstance-method}
