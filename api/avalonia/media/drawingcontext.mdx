```csharp
public void DrawEllipse(Avalonia.Media.IBrush brush, Avalonia.Media.IPen pen, Avalonia.Point center, double radiusX, double radiusY)
```

##### 参数 {#parameters-1}

`brush` [Avalonia.Media.IBrush](xref:Avalonia.Media.IBrush)

填充椭圆所用的画刷；为 `null` 时不填充。


`pen` [Avalonia.Media.IPen](xref:Avalonia.Media.IPen)

描边椭圆所用的画笔；为 `null` 时不描边。


`center` [Avalonia.Point](xref:Avalonia.Point)

The location of the center of the ellipse.


`radiusX` double

The horizontal radius of the ellipse.


`radiusY` double

The vertical radius of the ellipse.


##### 备注 {#remarks}

画刷和画笔都可以为 null。画刷为 null 时不作填充，
画笔为 null 时不作描边；两者都为 null 时，这次绘制便什么也看不见。

#### DrawRectangle 方法 {#drawrectangle-method}

用指定的 Brush 和 Pen 画一个矩形。

```csharp
public void DrawRectangle(Avalonia.Media.IBrush brush, Avalonia.Media.IPen pen, Avalonia.Rect rect, double radiusX, double radiusY, Avalonia.Media.BoxShadows boxShadows)
```

##### 参数 {#parameters-9}

`brush` [Avalonia.Media.IBrush](xref:Avalonia.Media.IBrush)

填充矩形所用的画刷；为 `null` 时不填充。


`pen` [Avalonia.Media.IPen](xref:Avalonia.Media.IPen)

描边矩形所用的画笔；为 `null` 时不描边。


`rect` [Avalonia.Rect](xref:Avalonia.Rect)

矩形边界。


`radiusX` double

The radius in the X dimension of the rounded corners.
This value will be clamped to the range of 0 to Width/2


`radiusY` double

The radius in the Y dimension of the rounded corners.
This value will be clamped to the range of 0 to Height/2


`boxShadows` [Avalonia.Media.BoxShadows](xref:Avalonia.Media.BoxShadows)

盒阴影效果的各项参数


##### 备注 {#remarks-2}

The brush and the pen can both be null. If the brush is null, then no fill is performed.
If the pen is null, then no stroke is performed. If both the pen and the brush are null, then the drawing is not visible.

</section>
