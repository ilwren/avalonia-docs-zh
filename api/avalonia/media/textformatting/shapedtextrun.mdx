## 备注 {#remarks}

Glyph data in the underlying [Avalonia.Media.TextFormatting.ShapedTextRun.ShapedBuffer](xref:Avalonia.Media.TextFormatting.ShapedTextRun.ShapedBuffer) is immutable after shaping:
LTR buffers are in ascending-cluster (logical) order, RTL buffers are in
descending-cluster (visual) order. [Avalonia.Media.TextFormatting.BidiReorderer](xref:Avalonia.Media.TextFormatting.BidiReorderer) only reorders runs,
it never mutates glyph order.

Ref-counted: the initial constructor call establishes one reference. Call
[Avalonia.Media.TextFormatting.ShapedTextRun.AddRef](xref:Avalonia.Media.TextFormatting.ShapedTextRun.AddRef) when taking an additional reference (e.g., when a
[Avalonia.Media.TextFormatting.TextRunCache](xref:Avalonia.Media.TextFormatting.TextRunCache) stores a shaped run a formatter is also about to use),
and [Avalonia.Media.TextFormatting.ShapedTextRun.Dispose](xref:Avalonia.Media.TextFormatting.ShapedTextRun.Dispose) to release. The underlying shaped buffer is disposed only
when the last reference is released.
