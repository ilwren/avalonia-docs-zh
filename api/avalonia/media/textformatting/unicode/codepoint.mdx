### HasScriptExtension 方法 {#hasscriptextension-method}

Determines whether the codepoint's Unicode Script_Extensions property contains
`script`.

```csharp
public bool HasScriptExtension(Avalonia.Media.TextFormatting.Unicode.Script script)
```

#### 参数 {#parameters-3}

`script` [Avalonia.Media.TextFormatting.Unicode.Script](xref:Avalonia.Media.TextFormatting.Unicode.Script)

The script to test.


#### 返回值 {#returns-3}

bool

`true` when the codepoint participates in `script` per UAX #24
(Script_Extensions); `false` otherwise.


#### 备注 {#remarks}

Backed by the UCD `ScriptExtensions.txt` data baked into [Avalonia.Media.TextFormatting.Unicode.UnicodeData](xref:Avalonia.Media.TextFormatting.Unicode.UnicodeData).
Codepoints without an explicit Script_Extensions entry fall back to the singleton set
of their primary [Avalonia.Media.TextFormatting.Unicode.Codepoint.Script](xref:Avalonia.Media.TextFormatting.Unicode.Codepoint.Script) property.

</section>
