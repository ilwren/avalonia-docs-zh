### Collapse 方法 {#collapse-method}

折叠给定的文本行并返回折叠后的各个运行；


#### 参数 {#parameters-1}

`textLine` [Avalonia.Media.TextFormatting.TextLine](xref:Avalonia.Media.TextFormatting.TextLine)

#### 返回值 {#returns}

[Avalonia.Media.TextFormatting.TextRun](xref:Avalonia.Media.TextFormatting.TextRun)[]


#### 备注 {#remarks}

实现方**必须**按逻辑顺序返回各个运行。调用方（`TextLineImpl.Collapse`）会把返回的数组
包进一个新的 [Avalonia.Media.TextFormatting.TextLine](xref:Avalonia.Media.TextFormatting.TextLine) 并通过 `FinalizeLine` 重新跑一遍 BiDi 重排，
因此若在此处预先套用视觉顺序，就会被重排第二次，
在 RTL 或双向混排的行上产出一团乱码。

请通过 `LogicalTextRunEnumerator` 遍历源行的各个运行，
而不要用 [Avalonia.Media.TextFormatting.TextLine.TextRuns](xref:Avalonia.Media.TextFormatting.TextLine.TextRuns)（那是 bidi 处理之后的视觉顺序）。
若某个实现只需要标准的“逻辑前缀 + 符号”形态，
用 [Avalonia.Media.TextFormatting.TextCollapsingProperties.CreateCollapsedRuns(Avalonia.Media.TextFormatting.TextLine,int,Avalonia.Media.TextFormatting.TextRun)](xref:Avalonia.Media.TextFormatting.TextCollapsingProperties.CreateCollapsedRuns%28Avalonia.Media.TextFormatting.TextLine%2CSystem.Int32%2CAvalonia.Media.TextFormatting.TextRun%29) 即可。
