Use this key to efficiently look up or group fonts in a collection by their style, weight,
and stretch characteristics. Keys are ordered lexicographically by [Avalonia.Media.Fonts.FontCollectionKey.Style](xref:Avalonia.Media.Fonts.FontCollectionKey.Style), then
