### Equals 方法 {#equals-method}

public bool Equals(object obj)
```

#### 参数 {#parameters-13}

#### 返回值 {#returns-9}

#### 备注 {#remarks-1}

Overriding Equals and GetHashCode on an [AvaloniaObject](xref:Avalonia.AvaloniaObject) is disallowed for two reasons:

- AvaloniaObjects are by their nature mutable
- The presence of attached properties means that the semantics of equality are
难以界定

this.

public void SetCurrentValue(Avalonia.AvaloniaProperty property, object value)
```

##### 参数 {#parameters-20}

`property` [Avalonia.AvaloniaProperty](xref:Avalonia.AvaloniaProperty)

该属性。

该值。


##### 备注 {#remarks-4}

This method is used by a component that programmatically sets the value of one of its
own properties without disabling an application's declared use of the property. The
method changes the effective value of the property, but existing data bindings and
styles will continue to work.

The new value will have the property's current [Avalonia.Data.BindingPriority](xref:Avalonia.Data.BindingPriority), even if
that priority is [Avalonia.Data.BindingPriority.Unset](xref:Avalonia.Data.BindingPriority.Unset) or
[Avalonia.Data.BindingPriority.Inherited](xref:Avalonia.Data.BindingPriority.Inherited).
