## 备注 {#remarks}

实现该接口的过渡，可在轻扫手势或程序化动画期间由一个归一化的进度值（0.0 到 1.0）驱动，
而不必通过 [Avalonia.Animation.IPageTransition.Start(Avalonia.Visual,Avalonia.Visual,bool,System.Threading.CancellationToken)](xref:Avalonia.Animation.IPageTransition.Start%28Avalonia.Visual%2CAvalonia.Visual%2CSystem.Boolean%2CSystem.Threading.CancellationToken%29) 以定时动画的方式播放。
